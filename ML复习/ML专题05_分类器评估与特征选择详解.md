### 0.2 老师在课上说过的话

**评估（week11）**
1. **Holdout 的比喻**："I have a lot of questions… I will give some to you to practice… the remaining part will be held back. You will never see that part. That part will be used as the exam questions." 训练集是练习题，测试集是考题。
2. **为什么要 validation set**：模型有 **hyperparameter（超参数）**，"could not be directly estimated from the training data"。例如决策树的叶子最少样本数、剪枝阈值，"this hyperparameter should be determined by the validation data"。
3. **Class imbalance 用 stratified sampling**：癌症病人远少于正常人，随机抽样可能让训练集里少数类比例失真，所以 "perform the sampling independently for each class"。
4. **为什么要重复、取平均**：一次评估的结果是个随机变量。老师举了新加坡空气质量和模拟考的例子："only if we take multiple tests, then take the average… provides a more reliable evaluation."
5. **k-fold 的局限**：同一折的样本总是一起当训练、一起当测试，所以要 repeated k-fold。外层循环每次 reshuffle（重新打乱）数据，再做一遍 k-fold。
6. **LOOCV**：数据多时 "computationally intensive… impractical"；模型很简单（如 Fisher LDA 有闭式解）时可以用。
7. **Precision 和 recall 要一起看**："We cannot consider the precision only. We also cannot consider the recall only… only if the classifier has both high recall and high precision, then we say it is a good model." 只报一个指标时，"normally we report F1 score"。
8. **ROC 的来历**：Bayes 分类默认阈值 0.5，但癌症诊断 "we should be very careful"，阈值可以调低。每个阈值对应 ROC 上一个点。AUC "should be between 0.5 and 1… the higher the better"。

**特征选择（week12）**
9. **Curse of dimensionality 是 "very important concept"**，有两个方面：data sparsity（数据稀疏）和 distance concentration（距离集中）。
10. **Peaking 的启示**："the performance on the training data is not our objective"；要尽量多收集训练样本，并且只用一部分重要特征。"Feature selection should be an important step in machine learning system design."
11. **选择 vs 提取**：特征选择保留原始特征的物理意义（体重就是体重）；特征提取压缩信息更高效，但新特征没有直观含义。
12. **不能简单取排名靠前的特征**："Actually, the answer is no." 好的子集要 "maximum relevance and minimum redundancy"。老师打了个比方：一个人能力再强，和队友合作不好也不行。
13. **Exhaustive search**："optimal in theory, but impractical"，只有特征很少（比如 10 个）时可行。
14. **后向剔除每一步选"去掉后剩余子集分数最大"的那个特征**："the removal of this feature has the least impact"。
15. **Embedded = Lasso**：L1 惩罚 "equivalent to penalize the number of features"，系数被压到 0 的特征就被剔除了。
16. **实践中两者结合**：先用单特征评价去掉明显没用的特征，再做子集选择。

# Part A：分类器评估

## 1. Evaluation procedures（评估过程）

核心原则：**测试数据不能参与训练**。我们关心的是模型在没见过的数据上的表现（generalization，泛化）。

### 1.1 Holdout method（留出法）

- 留出一部分数据当测试集：通常 70–80% 训练、20–30% 测试。
- 也可以分三份：60–70% 训练、15–20% 验证、15–20% 测试。
- **Validation set（验证集）**：在训练阶段用来选超参数、决定何时停止训练。
- **Test set（测试集）**：训练全部结束后才用，报告最终性能。
- **问题**：随机划分时各类在训练集和测试集里的比例可能失衡。class imbalance（类别不平衡）时更严重。
- **解决**：**stratified random sampling（分层随机抽样）**，在每一类内部分别按 70/30 抽。

> **看图（课件 p.3 和 p.5）**：p.3 是两种划分比例；p.5 是类别不平衡问题和分层抽样。

![课件 p.3 和 p.5](figs/ev/s7_p3_p5.png)

### 1.2 Repeated holdout（重复留出法）

随机做多次 holdout，取所有性能的平均值。多次划分后，训练集和测试集更可能都包含各类的代表性数据。

### 1.3 k-fold cross-validation（k 折交叉验证）

1. 把数据随机分成 $k$ 个**互不重叠**的 fold（折）。
2. 轮流把每一折当测试集，其余 $k - 1$ 折合起来当训练集。
3. 一共训练 $k$ 个模型，在 $k$ 个测试折上评估，报告**平均性能**。

常用 $k = 5$ 或 10。好处是**每个样本都恰好当过一次测试样本**，数据利用充分。

### 1.4 Leave-one-out CV（留一法，LOOCV）

k-fold 的极端情况，$k = N$（样本总数）：
- 每次只用 1 个样本测试，其余 $N - 1$ 个训练；
- 要训练 $N$ 次，计算量很大，只在样本很少时用。

### 1.5 Repeated k-fold CV（重复 k 折交叉验证）

**动机**：k-fold 的结果依赖于这一次怎么分折，"can be noisy"。每次划分不同，平均值也不同。

**步骤**（课件 p.11）：
1. 令 repeat = 1。
2. 做一次 k-fold CV，得到这一轮的平均性能。
3. repeat = repeat + 1，**重新打乱（reshuffle）数据**。
4. 回到第 2 步，直到达到预设轮数（如 50 轮）。
5. 计算所有轮的平均性能。

> **看图（课件 p.8、p.9、p.11）**：p.8 是 5 折交叉验证的示意，每一行一次实验，白色那一折做测试，最后把 5 个误差平均。p.9 是 LOOCV。p.11 是 repeated k-fold 的五步。

![课件 p.8、p.9、p.11](figs/ev/s7_p8_p9_p11.png)

> **看图 1-1**：80 个样本、LDA 分类器，把每种评估过程各独立重做 60 次，看估计出的 accuracy 有多不稳定。
> - 一次 holdout 的估计值从 0.67 到 0.96 都有（std 0.063）；
> - 一次 5-fold 的 std 是 0.014；
> - 重复 20 次的 5-fold 的 std 只有 0.003。
>
> 这就是老师说的"取平均才可靠"。

![图 1-1](figs/ev/fig1_cv_variance.png)

### 1.6 五种方法对比（论述题常用）

| 方法 | 做法 | 优点 | 缺点 |
|---|---|---|---|
| Holdout | 一次随机划分 70/30 | 简单，只训练一次 | 估计值依赖于这一次划分，方差大；测试数据没用于训练，浪费数据 |
| Repeated holdout | 多次随机划分取平均 | 估计更稳定 | 有的样本可能从未当过测试样本 |
| k-fold CV | 分 $k$ 折轮流测试，取平均 | 每个样本都测试一次，数据利用充分 | 训练 $k$ 次；结果仍受分折方式影响 |
| LOOCV | $k = N$ | 几乎用全部数据训练，结果确定（没有随机划分） | 训练 $N$ 次，计算量大，只适合小样本 |
| Repeated k-fold | 每轮重新打乱后做 k-fold，多轮取平均 | 方差最小，最可靠 | 计算量最大（轮数 × $k$ 次训练） |

## 2. Evaluation metrics（评估指标）

### 2.1 Confusion matrix（混淆矩阵）

两类问题里，把关心的那一类叫 **positive（正类）**，例如 "cancer"；另一类叫 **negative（负类）**，例如 "normal"。

| | 含义 |
|---|---|
| **TP**（true positive，真阳性） | 正类样本被正确判为正类 |
| **FP**（false positive，假阳性） | 负类样本被错判为正类 |
| **TN**（true negative，真阴性） | 负类样本被正确判为负类 |
| **FN**（false negative，假阴性） | 正类样本被错判为负类 |

**记法**：第二个字母是**预测结果**，第一个字母说预测**对不对**。FN 就是"预测为 N，预测错了"，即真实为正。

课件例子（**行 = 预测，列 = 真实**）：

| | 真实 Positive | 真实 Negative |
|---|---|---|
| **预测 Positive** | TP = 85 | FP = 4 |
| **预测 Negative** | FN = 2 | TN = 9 |

### 2.2 全部指标

| 指标 | 公式 | 含义 | 课件例子 |
|---|---|---|---|
| **Accuracy（准确率）** | $\dfrac{TP + TN}{TP + FP + FN + TN}$ | 判对的比例 | $94/100 = \mathbf{94\%}$ |
| **Error rate（错误率）** | $\dfrac{FP + FN}{N} = 1 - \text{Accuracy}$ | 判错的比例 | $6/100 = \mathbf{6\%}$ |
| **Sensitivity（灵敏度）** | $\dfrac{TP}{TP + FN}$ | 正类样本中被判对的比例 | $85/87 = \mathbf{97.7\%}$ |
| **Specificity（特异度）** | $\dfrac{TN}{TN + FP}$ | 负类样本中被判对的比例 | $9/13 = \mathbf{69.2\%}$ |
| **Precision（精确率）** | $\dfrac{TP}{TP + FP}$ | **预测为正**的样本中真为正的比例 | $85/89 = \mathbf{95.5\%}$ |
| **Recall（召回率）** | $\dfrac{TP}{TP + FN}$，**= Sensitivity** | **真实为正**的样本中被找出来的比例 | **97.7%** |
| **F-score（F1）** | $\dfrac{2\cdot P\cdot R}{P + R} = \dfrac{2TP}{2TP + FP + FN}$ | precision 和 recall 的调和平均 | $170/176 = \mathbf{0.966}$ |
| **TPR**（true positive rate） | $\dfrac{TP}{TP + FN}$ = Sensitivity = Recall | | 97.7% |
| **FPR**（false positive rate） | $\dfrac{FP}{FP + TN} = 1 - \text{Specificity}$ | 负类样本被误判为正的比例 | $4/13 = 30.8\%$ |

> **看图 2-1**：每个指标用到混淆矩阵的哪些格子。橙色是分子，橙色加蓝色是分母。
> - precision 看"预测为正"那一**行**；
> - recall / sensitivity 看"真实为正"那一**列**；
> - specificity 看"真实为负"那一列。

### 2.3 Precision 和 recall 的直观例子（课件 p.17–p.19）

四个陈述里有三个是对的：(a)、(b)、(d)。让你"选出所有正确的"：

| 你选了 | Recall（对的有没有漏） | Precision（选的有没有错） | F |
|---|---|---|---|
| 只选 (a) | $1/3 = 33.3\%$ | $1/1 = 100\%$ | 0.5 |
| 全选 (a)(b)(c)(d) | $3/3 = 100\%$ | $3/4 = 75\%$ | 0.857 |
| 选 (a)(b)(d) | 100% | 100% | 1 |

- 只追求 precision，就只挑最有把握的（漏很多）；
- 只追求 recall，就全选（错很多）。
- **所以要一起看，或者看 F-score。**

![课件 p.17–p.19](figs/ev/s7_p17_p19.png)

### 2.4 两个陷阱（考试必看）

**陷阱 1：行列方向**

课件和 23-24 S2 真题都是"行 = 预测，列 = 真实"，但很多教材反过来。**先看表头再读数**。

如果看反了：
- FP 和 FN 互换；
- precision 和 recall 互换，specificity 也会算错；
- accuracy 和 F-score 不变。

**陷阱 2：类别不平衡时 accuracy 会骗人**

例如 1000 人里只有 50 个病人：
- 一个把所有人都判为"正常"的分类器，accuracy 也有 95%，但一个病人都没找出来（recall = 0）。
- 这时要看 precision、recall、F-score、specificity 或 AUC。

### 2.5 真题：23-24 S2 Q3(a)（8 分）

> 行 = 预测，列 = 真实：TP = 126，FP = 11，FN = 15，TN = 100，共 252 个。

| 指标 | 计算 | 结果 |
|---|---|---|
| Accuracy | $\dfrac{126 + 100}{252}$ | **0.8968** |
| Precision | $\dfrac{126}{126 + 11} = \dfrac{126}{137}$ | **0.9197** |
| Recall | $\dfrac{126}{126 + 15} = \dfrac{126}{141}$ | **0.8936** |
| F-score | $\dfrac{2(0.9197)(0.8936)}{0.9197 + 0.8936} = \dfrac{252}{278}$ | **0.9065** |

> 可以顺手补两项：specificity $= 100/111 = 0.9009$，error rate $= 0.1032$。每个指标写公式、代数、给结果，再用一句话说明含义。

## 3. ROC curve（受试者工作特征曲线）和 AUC

### 3.1 为什么需要

分类器通常输出一个分数，例如后验概率 $P(\omega_1\mid x)$，再和**阈值**比较。Bayes 规则默认阈值 0.5。但在癌症诊断里，漏诊（FN）的代价远大于误诊（FP），可以把阈值调低。

**阈值一变，TP、FP、TN、FN 全变**，所有指标都跟着变。与其比较一堆混淆矩阵，不如把所有阈值下的表现画成一条曲线，这就是 ROC。

### 3.2 定义

- 横轴：$\text{FPR} = \dfrac{FP}{FP + TN} = 1 - \text{specificity}$
- 纵轴：$\text{TPR} = \dfrac{TP}{TP + FN}$ = sensitivity = recall
- 每个阈值对应 ROC 上一个点，连起来就是 ROC 曲线。

**几个特殊点**：
- 阈值极高（全判负）：$(0, 0)$；
- 阈值极低（全判正）：$(1, 1)$；
- 完美分类器经过 $(0, 1)$，即左上角。

**AUC（area under the curve，曲线下面积）** 衡量分类器区分两类的能力：

| AUC | 含义 |
|---|---|
| 1 | 完美区分所有正负样本 |
| 0.5 | 对角线，相当于随机猜 |
| 0 | 完全反了：把所有负类判成正、正类判成负 |
| $0.5 < \text{AUC} < 1$ | 有较大概率区分正负；**越大越好** |

AUC 还有一个直观解释：随机挑一个正样本和一个负样本，正样本分数更高的概率。

> **看图（课件 p.22、p.23、p.25）**：p.22 是 TPR 和 FPR 的定义；p.23 是 ROC 和阴影部分的 AUC；p.25 是不同分类器的 ROC：越靠左上越好，红色虚线是随机分类器。

![课件 p.22、p.23、p.25](figs/ev/s7_p22_p23_p25.png)

### 3.3 手算 ROC（可能的计算变体）

5 个正样本的分数：0.95、0.85、0.70、0.60、0.40；5 个负样本：0.80、0.55、0.35、0.20、0.10。规则：分数 $\ge t$ 判为正。

把所有分数从高到低排，每个分数当一次阈值：

| 阈值 $t$ | 判为正的样本 | TP | FP | TPR | FPR |
|---|---|---|---|---|---|
| 0.95 | 正 0.95 | 1 | 0 | 0.2 | 0 |
| 0.85 | + 正 0.85 | 2 | 0 | 0.4 | 0 |
| 0.80 | + 负 0.80 | 2 | 1 | 0.4 | 0.2 |
| 0.70 | + 正 0.70 | 3 | 1 | 0.6 | 0.2 |
| 0.60 | + 正 0.60 | 4 | 1 | 0.8 | 0.2 |
| 0.55 | + 负 0.55 | 4 | 2 | 0.8 | 0.4 |
| 0.40 | + 正 0.40 | 5 | 2 | 1.0 | 0.4 |
| 0.35 | + 负 0.35 | 5 | 3 | 1.0 | 0.6 |
| 0.20 | + 负 0.20 | 5 | 4 | 1.0 | 0.8 |
| 0.10 | + 负 0.10 | 5 | 5 | 1.0 | 1.0 |

**快捷画法**：从 $(0, 0)$ 出发，按分数从高到低，遇到正样本往上走 $1/5$，遇到负样本往右走 $1/5$。

**AUC**：把曲线下面积按竖条加起来。
- FPR 从 0 到 0.2，高度 0.4；从 0.2 到 0.4，高度 0.8；从 0.4 到 1，高度 1。

$$\text{AUC} = 0.2\times 0.4 + 0.2\times 0.8 + 0.6\times 1 = 0.08 + 0.16 + 0.6 = 0.84$$

用"正样本分数高于负样本的比例"验证：25 对里有 21 对正样本分数更高，$21/25 = 0.84$。

# Part B：特征选择

## 4. Curse of dimensionality（维数灾难）

处理高维数据时遇到的种种困难统称维数灾难，主要有两个方面：

1. **Data sparsity（数据稀疏）**：高维空间体积随维数指数增长，有限的样本"不够用"，大部分区域没有数据。
2. **Distance concentration（距离集中）**：维数很高时，所有样本两两之间的距离趋于同一个值。最近邻和最远邻差不多远，基于距离的方法（KNN、K-means、聚类）失去意义。

> **看图 4-1**：在 $d$ 维单位立方体里撒 300 个均匀随机点。
> - 左：各点到查询点的距离除以平均距离。$d = 2$ 时分布很宽；$d = 1000$ 时全挤在 1 附近。
> - 右：$\dfrac{\text{最远} - \text{最近}}{\text{最近}}$ 随维数下降，$d = 1000$ 时只剩约 0.1。也就是说，最远的点只比最近的点远 10%。

![图 4-1](figs/ev/fig4_distance_concentration.png)

**为什么要减少特征数**（课件 p.2）：
1. **计算复杂度**：特征越多，计算越多。对非线性分类器尤其严重。
2. **泛化能力**：训练样本数与分类器自由参数个数之比越大，泛化越好。特征多意味着参数多。样本有限时，特征越少越符合"好泛化"的要求。

> **看图（课件 p.1、p.4、p.5）**：p.1 是维数灾难的两个方面；p.4–p.5 是特征选择和特征提取的区别（§6）。

## 5. Peaking phenomenon（峰值现象）

### 5.1 现象

以线性分类器 $y = w^Tx + w_0$ 为例：$l$ 个特征就有 $l + 1$ 个未知参数，样本数 $N$ 必须远大于 $l + 1$ 才能估计得好。

- **训练样本数 $N$ 固定**时，随着特征数 $l$ 增加，错误率**先下降，到某个临界值后反而上升**。
- **$N$ 越大**，峰值出现得越晚（能用的特征越多），最低错误率也越低。

### 5.2 原因

- 理论上，特征越多信息越多，Bayes 错误率不会上升。
- 但参数要从有限样本中估计。特征数增加，参数数随之增加（例如协方差矩阵有 $l(l + 1)/2$ 个参数），每个参数的估计越来越不准；
- 加上高维空间数据稀疏，分类器开始拟合噪声，导致过拟合。

### 5.3 指导意义（23-24 S2 这一问占一半分数）

**对数据采集**：
- 训练样本数要和特征数相称。想用更多特征，就要采集更多样本。
- 样本少时只能用少量特征；样本多时才能用更多特征获得更好性能。
- 先估计能拿到多少样本，再决定测量和使用多少特征。

**对特征选择**：
- 样本有限时，用全部特征不是最好的，要做特征选择或特征提取，把维数降到峰值附近。
- 最优特征数可以用交叉验证确定：画性能随特征数变化的曲线，取峰值点。
- 留下判别力强、彼此不冗余的特征。

> **看图（课件 p.6–p.8）**：p.7 是课件的 peaking 示意图：两条曲线 $N = N_1$ 和 $N = N_2$（$N_2 \gg N_1$），各有一个最低点 $l_1 < l_2$。p.8 是结论："for a small number of training data, a small number of features must be used"。

![课件 p.6–p.8](figs/ev/s9_p6_p8.png)

> **看图 5-1**：模拟实验。第 $k$ 个特征的判别力按 $1/\sqrt k$ 递减，分类器用估计出的类均值做最小距离分类。
> - 每类 5 个样本时，约 12 个特征最好；
> - 每类 20 个时约 30 个最好；
> - 每类 100 个时约 120 个最好。
>
> 三条曲线完全对应课件的结论。

## 6. Feature selection（特征选择） vs feature extraction（特征提取）

| | Feature selection | Feature extraction |
|---|---|---|
| 做什么 | 从原始特征中**选一个子集**，例如 $\{x_1, \dots, x_5\} \to \{x_1, x_2, x_5\}$ | 由原始特征**构造新特征**，例如 $v_1 = f_1(x_1, \dots, x_5)$ |
| 物理意义 | 保留：体重还是体重 | 丢失：新特征是组合，难以解释 |
| 信息 | 没选的特征的信息丢了 | 把所有特征的信息压缩进少数几个新特征，更高效 |
| 测量成本 | 没选的特征以后不用测了 | 仍然要测所有原始特征 |
| 例子 | filter、wrapper、Lasso | **PCA**（principal component analysis，主成分分析）、LDA 投影 |

## 7. Individual feature evaluation（单特征评价）

**第一步**是逐个看特征，单独评价它的判别能力。这远不是最优的，但能先找出并扔掉"坏"特征，减轻后面子集搜索的计算负担。

课件给了两种评价方法，代表两种对"好特征"的理解。

### 7.1 Fisher's ratio（Fisher 比）：class separability（类可分性）

两类在这个特征上的均值为 $m_1$、$m_2$，标准差为 $\sigma_1$、$\sigma_2$：

$$R = \frac{(m_1 - m_2)^2}{\sigma_1^2 + \sigma_2^2}$$

- 分子是**类间差异**，分母是**类内散度**。
- 好特征：类间差异大、类内方差小。**$R$ 越大越有判别力。**
- 适用于**连续特征**。它就是 LDA 的 Fisher 准则在一维上的形式。

**例子**：

| 特征 | $m_1, \sigma_1$ | $m_2, \sigma_2$ | $R$ |
|---|---|---|---|
| A | 5, 1 | 3, 1 | $4/2 = \mathbf{2.0}$ |
| B | 10, 4 | 4, 4 | $36/32 = 1.125$ |
| C | 2, 0.5 | 2.2, 0.5 | $0.04/0.5 = 0.08$ |

B 的均值差最大（6），但类内方差也大，所以 $R$ 不如 A。**只看均值差是不够的。**

### 7.2 Mutual information（互信息）：relevance（相关性）

好特征应当包含大量关于类别标签的信息。特征 $x$ 和类别 $y$ 的互信息：

$$MI(x, y) = E(x) + E(y) - E(x, y)$$

- $E(x) = -\sum_i p(x = u_i)\log p(x = u_i)$；$E(y)$ 同理。
- $E(x, y) = -\sum_i\sum_j p(x = u_i, y = c_j)\log p(x = u_i, y = c_j)$，是联合熵。
- $MI \ge 0$；$x$ 和 $y$ 独立时 $MI = 0$。**$MI$ 越大，特征越相关。**
- 适用于**离散特征**。连续特征可以先离散化，例如把年龄分成 0–20、20–40……几段。

**例子**：二值特征 $x$，两类各 40 个样本。

| | $y = \omega_1$ | $y = \omega_2$ |
|---|---|---|
| $x = 0$ | 30 | 10 |
| $x = 1$ | 10 | 30 |

计算步骤（log 以 2 为底）：
- $E(x) = 1$（40 : 40）；$E(y) = 1$（40 : 40）。
- 联合概率是 0.375、0.125、0.125、0.375，所以
  $$E(x, y) = -2(0.375\log_2 0.375) - 2(0.125\log_2 0.125) = 1.0613 + 0.75 = 1.8113$$
- $MI = 1 + 1 - 1.8113 = \mathbf{0.1887}$。

对照：
- 如果四格都是 20（特征与类别无关），$MI = 0$；
- 如果是 40、0、0、40（特征完全决定类别），$MI = 1$。

> **看图（课件 p.10、p.12、p.13）**：p.10 是 Fisher's ratio 的一维示意和公式；p.12–p.13 是互信息和各个熵的公式，注意底部红字 "usually used for continuous / discrete"。

## 8. Feature subset selection（特征子集选择）

### 8.1 为什么不能直接取排名前 m 的特征

**问题**：给定全集 $X = \{x_1, \dots, x_n\}$，选子集 $Z = \{z_1, \dots, z_m\}$（$m < n$），使分类性能最好。

**答案是不能**直接取单特征排名前 $m$ 的：
- 排名靠前的特征之间可能**高度相关**。比如身高和腿长单独看都很好，但选了一个之后另一个几乎不提供新信息，子集里有严重的**冗余（redundancy）**。
- 两个单独看很弱的特征，组合起来可能很强（互补）。
- 好的子集要 **maximum relevance, minimum redundancy（最大相关、最小冗余）**。所以要按"集合"来评价。

### 8.2 两个组成部分（总复习 p.20）

子集选择算法 = **search algorithm（搜索算法）** + **evaluation criterion（评价准则）**。
- 搜索算法负责**生成候选特征子集**；
- 评价准则负责**评价候选子集的好坏**。

两者循环交互，最后输出选中的子集。

> **看图（课件 p.15、p.17、p.18）**：p.15 是 "The answer is no" 和最大相关最小冗余；p.17 是搜索算法与评价准则的交互图；p.18 是穷举搜索。

![课件 p.15、p.17、p.18](figs/ev/s9_p15_p17_p18.png)

### 8.3 Search algorithm（搜索算法）

| 方法 | 做法 | 特点 |
|---|---|---|
| **Exhaustive search（穷举）** | 枚举所有 $2^n - 1$ 个非空子集 | **optimal（最优）**，一定不会漏掉最优子集；但 $n$ 大时计算量不可接受（$n = 30$ 就有约 $10^9$ 个子集），只在 $n$ 很小时用 |
| **Sequential forward selection（顺序前向选择，SFS）** | **bottom-up（自底向上）**：从空集开始，每步从未选特征中加入使准则最好的一个，直到满足停止准则 | **sub-optimal（次优）**，快；特征一旦加入就不能删除（nesting effect，嵌套效应） |
| **Sequential backward elimination（顺序后向剔除，SBE）** | **top-down（自顶向下）**：从全集开始，每步去掉一个"去掉后剩余子集准则最好"的特征，也就是最不重要的那个 | 次优；一开始就要在高维全集上评价，计算量比 SFS 大；被删掉的特征不能再加回来 |

**停止准则**：
- 选够了预定的特征数；
- filter 法：可分性度量不再提高；
- wrapper 法：验证集上的准确率达到最优。

**SFS / SBE 手算示例**：4 个特征，选 3 个。准则 $J$ 越大越好，各子集的 $J$ 已知：

| 子集 | $J$ | 子集 | $J$ | 子集 | $J$ |
|---|---|---|---|---|---|
| $\{x_1\}$ | 1.2 | $\{x_1, x_2\}$ | 1.4 | $\{x_1, x_2, x_3\}$ | 2.4 |
| $\{x_2\}$ | 1.0 | $\{x_1, x_3\}$ | 2.1 | $\{x_1, x_2, x_4\}$ | 1.9 |
| $\{x_3\}$ | 0.7 | $\{x_1, x_4\}$ | 1.6 | $\{x_1, x_3, x_4\}$ | **2.6** |
| $\{x_4\}$ | 0.4 | $\{x_2, x_3\}$ | 1.8 | $\{x_2, x_3, x_4\}$ | 2.2 |
| | | $\{x_2, x_4\}$ | 1.5 | 全集 | 2.7 |
| | | $\{x_3, x_4\}$ | 1.1 | | |

**SFS**：
1. 第 1 步：四个单特征中 $x_1$ 最大（1.2），选 $x_1$。
2. 第 2 步：比较 $\{x_1, x_2\}$ 1.4、$\{x_1, x_3\}$ 2.1、$\{x_1, x_4\}$ 1.6，加入 $x_3$。
3. 第 3 步：比较 $\{x_1, x_3, x_2\}$ 2.4、$\{x_1, x_3, x_4\}$ 2.6，加入 $x_4$。

结果 $\{x_1, x_3, x_4\}$。

**SBE**：从全集出发，比较去掉每个特征后的 $J$。
- 去 $x_1$ → 2.2；去 $x_2$ → **2.6**；去 $x_3$ → 1.9；去 $x_4$ → 2.4。
- 去掉 $x_2$ 影响最小，删 $x_2$。

结果也是 $\{x_1, x_3, x_4\}$。

注意：$x_2$ 单独排第二（1.0），但最后被淘汰了。这说明它和 $x_1$ 冗余：$\{x_1, x_2\}$ 只有 1.4，比 $\{x_1, x_3\}$ 的 2.1 低得多。

> **看图（课件 p.19 和 p.20）**：前向选择和后向剔除的文字定义。

![课件 p.19 和 p.20](figs/ev/s9_p19_p20.png)

### 8.4 Evaluation criterion（评价准则）

**(1) Classification performance（分类性能）**
- 在候选子集上训练分类器，用分类准确率（或错误率）作为准则。
- 选出的子集和分类器匹配；**换一个分类器可能选出不同的子集**。

**(2) Separability measures（可分性度量）**
- 估计各类分布之间的重叠程度，偏好重叠最小（可分性最大）的子集。
- 优点：选出的子集**与最终分类器无关**；不需要训练大量分类器，**计算更高效**。
- 缺点：估计分布重叠时所做的假设可能和真实分布不符。

两种可分性度量：

- **Mahalanobis distance（马氏距离）**：
  $$J_{1,2} = (m_1 - m_2)^TC^{-1}(m_1 - m_2)$$
  - $m_1$、$m_2$ 是两类在该子集上的均值向量，$C$ 是协方差矩阵。
  - 多类时把两两之间的 $J$ 加起来：$J = \sum_i\sum_{j>i} J_{i,j}$。
- **Scatter-based（基于散度矩阵）**：
  $$J = \mathrm{Tr}(S_W^{-1}S_B)\qquad\text{或}\qquad J = \frac{\mathrm{Tr}(S_B)}{\mathrm{Tr}(S_W)}$$
  - $S_B$ 是类间散度矩阵，$S_W$ 是类内散度矩阵，$\mathrm{Tr}$ 是迹（主对角线元素之和）。
  - 和 LDA 的 Fisher 准则同一个思路：类间大、类内小。

## 9. 三类特征子集选择方法：filter、wrapper、embedded（考过两次）

按**评价准则**分为三类。

### 9.1 Filter method（过滤法）

- **不把分类器放进循环**，用类可分性度量（Mahalanobis、scatter trace、Fisher ratio、互信息等）作为子集评价准则。
- 流程：全集 → 搜索算法生成子集 → 算可分性度量 → 满足停止准则？否则继续搜索。
- 停止准则：选够了特征数；可分性度量不再提高；其他。

### 9.2 Wrapper method（包裹法）

- **把分类器放进循环**，用分类性能（准确率、错误率）作为子集评价准则。
- 流程同上，只是"可分性度量"换成"训练分类器、在验证集上测准确率"。
- 停止准则：选够了特征数；验证集准确率达到最优；其他。

### 9.3 Embedded method（嵌入法）

- 学习算法**自带特征选择机制**，在训练过程中惩罚特征个数。
- 最典型的是 **Lasso**：
  $$J_{lasso}(\theta) = \frac12\left[\sum_i(\hat y_i - y_i)^2 + \lambda\sum_j\lvert\theta_j\rvert\right]$$
  L1 惩罚会把最不重要的特征的系数**压缩到 0**，这些特征就被剔除了。
- 决策树也有这个性质：只用分裂时选中的特征。

> **看图（课件 p.26–p.28）**：p.26 是三类方法的定义；p.27 是 filter 的流程图，中间方框是 Separability Measure；p.28 是 wrapper 的流程图，中间方框换成 Pattern Classifier。**考试画流程图就画这两张**（21-22 S2 Q4(a) 要求 "diagrams"）。

![课件 p.26–p.28](figs/ev/s9_p26_p28.png)

> **看图（课件 p.29、p.30、p.35）**：p.29–p.30 把 SFS 和两种准则结合起来，filter 用 $J = \mathrm{Tr}(S_B)/\mathrm{Tr}(S_W)$，wrapper 用 $J = \text{Accuracy}(\text{classifier trained on } F)$，每步选使 $J$ 最大的特征。p.35 是 Lasso。

![课件 p.29、p.30、p.35](figs/ev/s9_p29_p30_p35.png)

### 9.4 优缺点对比（23-24 S2 Q3(c) 9 分的标准答案）

| | Filter | Wrapper | Embedded |
|---|---|---|---|
| 评价准则 | 可分性度量，与分类器无关 | 分类器在验证集上的性能 | 模型训练中自带（如 L1 惩罚） |
| 优点 | 计算快，不用反复训练分类器，适合高维数据；子集不依赖特定分类器，通用；不易过拟合 | 直接针对所用分类器优化，考虑特征间的相互作用，通常精度最高 | 只训练一次，效率介于两者之间；也考虑特征间的相互作用 |
| 缺点 | 不针对最终分类器，分类性能不一定最好；分布假设可能不符；逐个评价时忽略冗余和组合效应 | 要反复训练分类器，计算量很大；样本少时容易对验证集过拟合；换分类器要重新选 | 依赖具体学习算法，结果不能直接迁移到别的模型；要调正则化参数 $\lambda$ |

**易错点**："穷举 / 前向 / 后向" 是**搜索算法**的分类，不是这三类方法。题目问 "three categories of feature subset selection methods" 时答 filter / wrapper / embedded。

## 10. 论述题范文（英文，可直接写）

### E1. Describe the evaluation procedures and metrics for classifiers（21-22 S2 Q3(c)，约 8 分）
（描述分类器的评估过程和评估指标。）

> **Procedures.** (1) **Holdout**: a subset of the data (e.g., 20–30%) is held back as test data and the rest is used for training; a validation set may also be split off to tune hyperparameters. Stratified random sampling keeps the class proportions in each subset. (2) **Repeated holdout**: several random holdouts are performed and the performance is averaged. (3) **k-fold cross-validation**: the data are divided into $k$ non-overlapping folds; each fold is used once as the test set while the other $k - 1$ folds are used for training, and the mean of the $k$ results is reported. (4) **Leave-one-out**: $k = N$, each sample is tested once; it is expensive and used only for small data sets. (5) **Repeated k-fold cross-validation**: k-fold CV is repeated many times with the data reshuffled each time, and the results of all repeats are averaged to reduce the variance of the estimate.
>
> **Metrics** (from the confusion matrix TP, FP, TN, FN): accuracy $= (TP + TN)/N$; error rate $= (FP + FN)/N$; sensitivity = recall $= TP/(TP + FN)$; specificity $= TN/(TN + FP)$; precision $= TP/(TP + FP)$; F-score $= 2PR/(P + R)$. The **ROC curve** plots the true positive rate against the false positive rate as the decision threshold varies; the **AUC** measures the ability to distinguish the classes (1 is perfect, 0.5 is random guessing).

> 【中文】
> **评估过程。** (1) **留出法**：留出一部分数据（如 20–30%）作为测试集，其余用于训练；还可以再分出验证集来调超参数。分层随机抽样使每个子集保持各类比例。(2) **重复留出法**：做多次随机留出，把性能取平均。(3) **k 折交叉验证**：把数据分成 k 个互不重叠的折，每一折轮流当一次测试集，其余 k − 1 折用于训练，报告 k 个结果的平均值。(4) **留一法**：k = N，每个样本测试一次；计算量大，只用于小数据集。(5) **重复 k 折交叉验证**：每次重新打乱数据，重复做多次 k 折交叉验证，把所有重复的结果取平均，以减小估计的方差。
>
> **指标**（由混淆矩阵的 TP、FP、TN、FN 计算）：准确率 = (TP + TN)/N；错误率 = (FP + FN)/N；灵敏度 = 召回率 = TP/(TP + FN)；特异度 = TN/(TN + FP)；精确率 = TP/(TP + FP)；F 值 = 2PR/(P + R)。**ROC 曲线**画出决策阈值变化时真阳性率对假阳性率的关系；**AUC** 衡量区分两类的能力（1 为完美，0.5 相当于随机猜）。

### E2. Explain k-fold and repeated k-fold cross-validation（22-23 S2 Q3(c)，约 6 分）
（解释 k 折交叉验证和重复 k 折交叉验证。）

> In **k-fold cross-validation**, the data set is randomly divided into $k$ completely distinct, non-overlapping folds. Each fold in turn is held back as the test set while all other folds together are used as the training set. In total $k$ models are trained and evaluated on the $k$ held-out folds, and the mean performance is reported. Every sample is used for testing exactly once; typical $k$ is 5 or 10.
>
> The estimate from a single k-fold run can be noisy: a different split of the data into folds gives a different mean estimate, and samples in the same fold are always trained and tested together. In **repeated k-fold cross-validation**, (1) set repeat = 1; (2) perform k-fold CV and record the average over the $k$ folds; (3) reshuffle the data and set repeat = repeat + 1; (4) go back to step 2 until a preset number of repeats (e.g., 50) is reached; (5) report the average over all repeats. This reduces the variance and gives a more reliable estimate, at the cost of more computation.

> 【中文】**k 折交叉验证**中，数据集被随机分成 k 个完全不同、互不重叠的折。每一折轮流作为测试集，其余各折合起来作为训练集。一共训练 k 个模型，在 k 个留出的折上评估，报告平均性能。每个样本恰好测试一次；常用 k = 5 或 10。
>
> 单次 k 折的估计可能有噪声：换一种分折方式就会得到不同的平均值，而且同一折里的样本总是一起训练、一起测试。**重复 k 折交叉验证**的步骤：(1) 令 repeat = 1；(2) 做一次 k 折交叉验证，记录 k 折的平均值；(3) 重新打乱数据，repeat = repeat + 1；(4) 回到第 2 步，直到达到预设的重复次数（如 50）；(5) 报告所有重复的平均值。这样降低了方差、估计更可靠，代价是计算量更大。

### E3. Peaking phenomenon and how it guides data collection and feature selection（23-24 S2 Q3(b)，8 分）
（峰值现象，以及它对数据采集和特征选择的指导意义。）

> **Definition.** For a finite number of training samples $N$, increasing the number of features $l$ first improves the performance of a classifier, but after a critical value, a further increase of $l$ increases the probability of error. This is the peaking phenomenon, a manifestation of the curse of dimensionality.
>
> **Reason.** The number of unknown classifier parameters grows with $l$ (e.g., $l + 1$ for a linear classifier, $l(l + 1)/2$ for a covariance matrix). With a fixed $N$, the parameters are estimated less and less accurately, the samples become sparse in the high-dimensional space, and the classifier starts to fit noise (overfitting).
>
> **Guidance for data collection.** $N$ must be large enough with respect to $l$. The more features we want to use, the more training samples we must collect; when more samples are available, the peak moves to a larger $l$ and the minimum error becomes lower.
>
> **Guidance for feature selection.** With a small training set, only a small number of features should be used. Using all available features is not optimal, so feature selection or extraction should be performed to reduce the dimensionality to around the peak. The optimal number of features can be determined by cross-validation, keeping discriminative and non-redundant features.

> 【中文】
> **定义。** 训练样本数 N 有限时，增加特征数 l 起初会提高分类器性能，但超过某个临界值后，再增加 l 反而会使错误概率上升。这就是峰值现象，是维数灾难的一种表现。
>
> **原因。** 分类器的未知参数个数随 l 增长（如线性分类器有 l + 1 个，协方差矩阵有 l(l + 1)/2 个）。N 固定时，参数估计越来越不准，样本在高维空间中变得稀疏，分类器开始拟合噪声（过拟合）。
>
> **对数据采集的指导。** N 相对 l 必须足够大。想用的特征越多，需要采集的训练样本就越多；样本更多时，峰值点移向更大的 l，最低错误率也更低。
>
> **对特征选择的指导。** 训练集小时，只应使用少量特征。用上全部特征不是最优的，应做特征选择或特征提取，把维数降到峰值附近。最优特征数可以用交叉验证确定，保留有判别力、不冗余的特征。

### E4. Filter vs wrapper: diagrams, difference, advantages and disadvantages（21-22 S2 Q4(a)；22-23 S2 Q3(a)）
（过滤法与包裹法：框图、区别、优缺点。）

> **Diagrams.** Filter: Full set → Search algorithm → candidate subsets → **Separability measure** → Stop? (No: back to search; Yes: output). Wrapper: the same loop, but the evaluation box is a **Pattern classifier** trained on the subset and evaluated on validation data.
>
> **Difference.** The filter method does not include a classifier in the loop; it uses class separability measures (e.g., Mahalanobis distance, $\mathrm{Tr}(S_W^{-1}S_B)$ or $\mathrm{Tr}(S_B)/\mathrm{Tr}(S_W)$) as the subset evaluation criterion. The wrapper method includes a classifier in the loop and uses classification performance (accuracy or error rate) as the criterion.
>
> **Filter.** Advantages: computationally efficient, since no classifiers are trained; scalable to high-dimensional data; the selected subset is independent of the final classifier; less prone to overfitting. Disadvantages: not optimized for the final classifier, so accuracy may be lower; the assumptions in estimating distribution overlap may not match the true distribution.
>
> **Wrapper.** Advantages: optimized for the specific classifier and accounts for feature interactions, so it usually gives better performance. Disadvantages: training a classifier for every candidate subset is very time-consuming; risk of overfitting the validation data; the subset may not suit other classifiers.
>
> **Procedure (filter + sequential forward selection).** Step 1: evaluate $J$ for each single feature and select the one with the largest separability. Step 2: add each remaining feature in turn to the selected set, evaluate $J$, and select the feature giving the largest $J$. Repeat until the stopping criterion is met: the required number of features is reached, or $J$ no longer improves.

> 【中文】
> **框图。** 过滤法：全部特征 → 搜索算法 → 候选子集 → **可分性度量** → 停止？（否：回到搜索；是：输出）。包裹法：同样的循环，但评价那一格换成在子集上训练、在验证数据上评估的**模式分类器**。
>
> **区别。** 过滤法的循环里没有分类器；它用类可分性度量（如马氏距离、Tr(S_W⁻¹S_B) 或 Tr(S_B)/Tr(S_W)）作为子集评价准则。包裹法的循环里有分类器，用分类性能（准确率或错误率）作为准则。
>
> **过滤法。** 优点：不用训练分类器，计算效率高；能扩展到高维数据；选出的子集与最终分类器无关；不容易过拟合。缺点：没有针对最终分类器优化，准确率可能较低；估计分布重叠时所做的假设可能与真实分布不符。
>
> **包裹法。** 优点：针对具体分类器优化，并考虑特征之间的交互，通常性能更好。缺点：每个候选子集都要训练一次分类器，非常耗时；有对验证数据过拟合的风险；选出的子集不一定适合其他分类器。
>
> **步骤（过滤法 + 顺序前向选择）。** 第 1 步：对每个单独的特征计算 J，选可分性最大的那个。第 2 步：把每个剩余特征依次加入已选集合，计算 J，选使 J 最大的特征加入。重复直到满足停止准则：达到要求的特征数，或 J 不再提升。

### E5. The three categories of feature subset selection methods（23-24 S2 Q3(c)，9 分）
（特征子集选择方法的三大类。）

> 按 §9.1–§9.4 写，三类各写四项：定义、怎么评价、优点、缺点。
>
> - **Filter**: no classifier in the loop; separability measures as criterion; fast, classifier-independent, less overfitting; may not be optimal for the final classifier.
> - **Wrapper**: classifier in the loop; classification accuracy as criterion; best accuracy, accounts for interactions; expensive, may overfit, classifier-specific.
> - **Embedded**: built-in mechanism penalizing the number of features during training, e.g., Lasso's L1 penalty shrinks the coefficients of unimportant features to zero; efficient (one training run) and considers interactions; tied to a specific learning algorithm and requires tuning $\lambda$.

> 【中文】
> - **过滤法（Filter）**：循环里没有分类器；用可分性度量作准则；快、与分类器无关、不易过拟合；对最终分类器不一定最优。
> - **包裹法（Wrapper）**：循环里有分类器；用分类准确率作准则；准确率最高，考虑交互；代价大、可能过拟合、依赖具体分类器。
> - **嵌入法（Embedded）**：训练过程中内置惩罚特征个数的机制，例如 Lasso 的 L1 惩罚把不重要特征的系数压到 0；高效（只训练一次），考虑交互；依赖特定的学习算法，需要调 λ。

### E6. Curse of dimensionality（4 分）
（维数灾难。）

> The curse of dimensionality refers to the difficulties of working with high-dimensional data. (1) **Data sparsity**: the volume of the feature space grows exponentially with the dimension, so the available samples cover it very sparsely. (2) **Distance concentration**: in high dimensions all pairwise distances tend to the same value, so distance-based methods lose their discriminating power. In addition, the number of classifier parameters grows with the dimension, so with limited samples the estimates become unreliable and the classifier overfits (peaking phenomenon). Remedies are collecting more data, feature selection, feature extraction such as PCA, and regularization.

> 【中文】维数灾难指处理高维数据时遇到的种种困难。(1) **数据稀疏**：特征空间的体积随维数指数增长，现有样本对它的覆盖非常稀疏。(2) **距离集中**：高维下所有两两距离趋于同一个值，基于距离的方法失去区分能力。此外，分类器参数个数随维数增长，样本有限时估计变得不可靠，分类器过拟合（峰值现象）。补救方法有：采集更多数据、特征选择、PCA 等特征提取、正则化。

### E7. Feature selection vs feature extraction; individual feature vs feature subset evaluation（6 分）
（特征选择与特征提取；单特征评价与特征子集评价。）

> **Selection vs extraction.** Feature selection chooses a subset of the original features, so the selected features keep their physical meaning and the unselected ones need not be measured. Feature extraction derives new features from all original features, e.g., PCA, compressing the information into fewer dimensions more efficiently but losing interpretability.
>
> **Individual vs subset.** Individual evaluation scores each feature separately, by Fisher's ratio $(m_1 - m_2)^2/(\sigma_1^2 + \sigma_2^2)$ for continuous features or by mutual information with the class label for discrete features. It is fast and useful for discarding bad features, but simply taking the top-ranked features may give a redundant subset, because top features can be strongly correlated, and it misses features that are only useful in combination. Subset evaluation scores feature combinations, aiming at maximum relevance and minimum redundancy, using a search algorithm (exhaustive, forward selection, backward elimination) together with an evaluation criterion (separability or classifier performance).

> 【中文】
> **选择与提取。** 特征选择从原始特征中挑一个子集，所以选中的特征保留物理意义，没选中的特征不必再测量。特征提取从全部原始特征导出新特征，例如 PCA，能更高效地把信息压缩到更少的维度，但失去了可解释性。
>
> **单特征与子集。** 单特征评价逐个给特征打分：连续特征用 Fisher 比 (m₁ − m₂)²/(σ₁² + σ₂²)，离散特征用它与类别标签的互信息。这种方法快，适合剔除坏特征；但直接取排名靠前的特征可能得到冗余的子集，因为靠前的特征可能强相关，而且会漏掉只有组合起来才有用的特征。子集评价给特征组合打分，目标是最大相关、最小冗余，使用搜索算法（穷举、前向选择、后向消除）加评价准则（可分性或分类器性能）。

### E8. Why is accuracy not enough? Explain precision, recall and ROC/AUC（6 分）
（为什么只看准确率不够？解释精确率、召回率和 ROC/AUC。）

> With imbalanced classes, a classifier that assigns every sample to the majority class can reach a high accuracy while detecting no positive samples. **Precision** $TP/(TP + FP)$ measures how many predicted positives are truly positive; **recall** $TP/(TP + FN)$ measures how many actual positives are found. Neither alone is sufficient: predicting very few positives gives high precision but low recall, and predicting everything positive gives full recall but low precision. The **F-score** combines them as a harmonic mean. Since all these metrics depend on the decision threshold, the **ROC curve** plots TPR against FPR for all thresholds, and the **AUC** summarizes the classifier's ability to separate the classes independently of any particular threshold: 1 is perfect, 0.5 is random.

> 【中文】类别不平衡时，把所有样本都判给多数类的分类器可以达到很高的准确率，却一个正样本都检测不到。**精确率** TP/(TP + FP) 衡量预测为正的样本中有多少真为正；**召回率** TP/(TP + FN) 衡量真实为正的样本中有多少被找到。单看哪一个都不够：只预测极少数为正，精确率高而召回率低；全部预测为正，召回率满分而精确率低。**F 值**用调和平均把两者结合起来。这些指标都依赖决策阈值，所以 **ROC 曲线**画出所有阈值下 TPR 对 FPR 的关系，**AUC** 不依赖任何具体阈值地概括分类器区分两类的能力：1 为完美，0.5 为随机。
