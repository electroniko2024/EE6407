## 1. 一页结论

1. **卷型固定**：Q1 是 GA；Q2、Q3 是监督学习；Q4 是聚类。每题 25 分。
2. **LDA 八卷全有**，七卷是"设计 + 分类 + 置信度"的计算。**今年几乎必考。**
3. **S1 卷和 S2 卷的内容明显分成两组**（最近三年都是 3 比 3）：
   - **S1 卷**每次都有**Bayes / 朴素贝叶斯**和**聚类评价指标**。
   - **S2 卷**每次都有**SVM**和**single linkage**。
   - 今年考的是 S1，所以 NB（很可能连带决策树）和聚类指标的概率高。
   - **但老师本学期 week9 讲 SVM 时说过**：往年给过 α 和 C 让你算 b，"**Maybe we can have a similar question this year. I'm not sure.**" week13 总复习又把"软间隔只能用 0 < α < C 的支持向量求 b"完整讲了一遍。**这是唯一一句针对"今年"的直接提示，比卷子统计出的规律更有分量，所以 SVM 计算的概率要明显提高**（见 §2、§6）。
4. **同一板块按变体轮换**，还没考过的变体最可能出：
   - 决策树的 **entropy / 信息增益**：老师说过"考试会指定用 entropy 还是 Gini"，而 Gini 已经考过。
   - **average linkage**。
   - **DB / CH / Rand 指数**。
   - **随机森林**。
5. **论述小问越来越多**，都是问"为什么 / 什么条件 / 怎么补救"。每道计算题后面基本都跟一句置信度。

### 2.3 和之前的预测比，哪里要改

1. **SVM 要上调**：之前按"S1 卷只有 1/3 考 SVM"给了 40%。但老师这学期明说"今年可能有类似的题"，总复习又讲得最长，应调到 **65% 左右**，而且题型很具体：**软间隔，给 α 和 C，求 w、b（只用 0 < α < C），再分类**。
2. **LDA 论述押 w₀ 更有把握**：总复习专门讲了 w₀ 的假设和调整方法，和之前押的方向一致。
3. **随机森林上调**：总复习讲得很细（两处随机、diversity、多数投票），从 30% 调到 **40%**。
4. **NB 里 Bernoulli 不能放**：按"变体轮换"Bernoulli 已经考过两次，但它是老师唯一说过"You must know this"的变体，总复习又现场做了一遍 Bernoulli 表，所以 Bernoulli 和 Multinomial / Gaussian 一样要准备。
5. **回归、数据准备略上调**：回归 20% → 25%，数据准备 10% → 15%。评估 / 特征选择总复习只点了名字，维持 25%。
6. **没有任何一句提示说哪些内容不考**，除了 MDA。

## 5. 五条出题规律

### 规律 1：S1 卷和 S2 卷各有一套"固定搭配"

| | 23-24 | 24-25 | 25-26 |
|---|---|---|---|
| **S1** | LDA + Gaussian NB；**五个指标** | Bayes + Gaussian NB；LDA + SVM；**Silhouette** | LDA；Bernoulli + Multinomial + Gini；**Dunn** |
| **S2** | **SVM** + LDA 对比；评估 / 特征选择；**single** | **软间隔 SVM**；Bernoulli + LDA；**single** | LDA；**软间隔 SVM**；**single** + K-means |

- **S1**：Bayes 家族 3 / 3，聚类指标 3 / 3，SVM 只有 1 / 3。
- **S2**：SVM 3 / 3，single linkage 3 / 3。
- 样本只有各 3 卷，不能当铁律。而且老师本学期对 SVM 有直接提示（§2），所以今年 S1 卷出 SVM 的可能性比这个规律显示的要高。

### 规律 2：LDA 是"保底题"，变化都在论述小问上

- 计算格式八年没变：给均值和散度矩阵 → 求 w、w₀ → 分类 → 距离与置信度。
- 论述小问每次换一个角度：
  - 23-24 S2：LDA vs SVM
  - 25-26 S1：优化表述
  - 25-26 S2：适用条件、高维小样本失效
- 下一个角度大概率是 **w₀ 的假设**，或者**为什么同时用 S_W⁻¹ 和 (m₁−m₂)**。

### 规律 3：同一板块按"没考过的变体"轮换

- **NB**：Gaussian → Bernoulli → Multinomial。
- **层次聚类**：single → complete → centroid，**average 还空着**。
- **聚类指标**：五个一起 → Silhouette → Dunn，**DB / CH / Rand 还没单独考过**。
- **决策树**：Gini 已考，**entropy 还空着**；老师原话"考试会指定用 entropy 还是 Gini"。

### 规律 4：长期没考的板块有可能"回归"，但回归时分值不大

- 评估、特征选择从 24-25 起已经 4 卷没出。
- 数据准备 5 卷没出，回归从来没出。
- 总复习 PPT 都列了这几块，范围没删。
- 如果出，大概是 5～8 分的论述小问，挂在监督学习题后面，不太会整题 25 分。

### 规律 5：计算题的形式基本不变，失分在细节

- 散度矩阵和协方差的换算（LDA 不除 N，Gaussian NB 要除以 N）。
- 软间隔只用 0 < α < C 的支持向量求 b。
- 层次聚类每步都写距离矩阵和合并高度。
- 每道计算题最后写置信度。

### 6.2 最可能的一张卷（主预测，已改）

LDA、SVM、NB 三块都要放进两道监督学习题里，最接近的是 **24-25 S1 的结构**："一题 Bayes 家族，一题 LDA + SVM"。

**Q2 朴素贝叶斯 + 决策树（25 分）**
- (a) 朴素贝叶斯计算，约 12 分，并要求 "state the assumptions"。变体三选一：
  - Bernoulli NB：老师最强调，总复习现场做过；
  - Multinomial NB，带 Laplace 平滑；
  - Gaussian NB，给散度矩阵，考"先除以 N"的陷阱。
- (b) 用 **entropy**（或题目指定的 Gini）选根节点，约 7 分。
- (c) 论述，约 6 分：随机森林，或"朴素"假设为什么还好用。

**Q3 LDA + SVM（25 分）**
- (a) LDA 设计 + 分类 + 距离 / 置信度，约 12 分。题目可能给协方差加样本数，要先换算成散度矩阵。
- (b) 软间隔 SVM：给支持向量、α 和 C，求 w、b（**只用 0 < α < C 的支持向量**），分类测试样本并说置信度，约 13 分。
- 如果出 LDA 论述（w₀ 的假设），就会挤掉 (a) 的一部分计算分。

**Q4 聚类（25 分）**
- (a) 4～6 个点的凝聚层次聚类，**average linkage**（其次是 complete 或 single），每步写距离矩阵，画带高度的树状图。约 10 分。
- (b) 给一张图选聚类算法，或描述 DBSCAN 步骤。约 7～8 分。
- (c) 解释一个评价指标，约 7 分。最可能是 Davies-Bouldin，其次 CH 或 Rand；也可能用 (a) 的结果算 Silhouette。

### 6.3 备选情形

- **备选 A（25-26 S2 的结构）**：Q2 整题 LDA（设计 + 置信度 + w₀ 论述）；Q3 整题 SVM（论述"支持向量是什么、为什么只用 0<α<C 求 b" + 由 α、C 求 w、b + 分类）。这样 NB 就不出，和 S1 卷的规律冲突，但符合老师对 SVM 的提示。
- **备选 B（原来的主预测，25-26 S1 的结构）**：Q2 整题 LDA + w₀ 论述；Q3 NB + entropy + 随机森林；不出 SVM。和 S1 卷规律一致，但要老师的"this year"那句不兑现。
- **评估 / 特征选择回归**：在某道题后面加一个 5～8 分小问，例如混淆矩阵、ROC / AUC、peaking、维数灾难。
