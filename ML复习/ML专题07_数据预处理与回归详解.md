### 0.2 老师在课上说过的话

**数据预处理（week6）**
1. **不是"把数据扔进开源代码"那么简单**："after we collect the data, we must carefully prepare the data." 而且 "the quality of data directly determines the quality of the model"。
2. **先搞清数据类型，这非常重要**：nominal 数据即使用数字编码，"male is 1, female is 0… the sum of the two values, what's the meaning?" 对 nominal 不能做算术运算。"we need to look at the nature of the data, not just based on the value."
3. **数据类型决定能用什么统计量**：nominal 用 mode；ordinal 用 median 更好；interval 和 ratio 才能用 mean。
4. **箱线图的须线**：老师逐步讲了课件的例子：$Q_1 = 73$、$Q_3 = 79$、$IQR = 6$，下栅栏 $73 - 9 = 64$，所以下须落在 $\ge 64$ 的最小数据值 70，上须落在 $\le 88$ 的最大值 84。
5. **离群点不一定是错误**：例如血压。年轻人群体里少数高血压是离群点，但老年人中高血压很常见，"they represent a new pattern… we may separately model this part of the data. If natural, not because of error, then we should keep them."
6. **离群点的来源**：老师举了身高单位写错的例子（1.79 m 记成 179），以及合并不同来源的数据集时出错。
7. **缺失值的相似样本插补**：同类样本里差异也可能很大（比如男生身高范围也很广），所以还可以用和缺失特征相关的其他特征去"预测"缺失值，比如建一个 $x_1 = f(x_2)$ 的关系。
8. **为什么要缩放**：一是基于距离的算法，"distance is a very important metric… one feature will dominate"；二是梯度下降，不同尺度会让参数更新步子差别很大，缩放后收敛更快更稳。
9. **降维的两条路**：feature extraction（PCA，生成新特征）和 feature selection（选原特征的子集，本课程重点讲后者，见专题 05）。

**回归（week11）**
10. **回归 vs 分类**：目标变量是数值（比如预测分数）就是回归；是类别（比如预测 A+、A、B 等级）就是分类。两者都是监督学习。
11. **噪声影响估计精度**：课件例子的真实模型是 $y = 0.5 + 2x + \varepsilon$。噪声越小，OLS 估计越接近真值；无噪声时恰好得到 $(0.5, 2)$。
12. **Lasso 为什么能把系数压成 0**：对小参数，例如 $\theta = 0.1$，L2 惩罚是 0.01，几乎不罚；L1 惩罚是 0.1，罚得相对重得多，所以 Lasso 会把小系数推到 0，"it will select the significant variables."
13. **Lasso 的 $\lambda$**：$\lambda$ 太大 → 很多变量被剔除，欠拟合；$\lambda$ 太小 → 无关变量也留下，过拟合。"The λ is a hyperparameter"，用验证集选。Lasso 没有解析解，要用数值方法迭代求解。
14. **$R^2$ 多高才算好要看领域**：预测人类行为的研究 $R^2$ 往往低于 0.5；测量很好的物理过程可以到 0.9 以上。

# Part A：数据预处理

## 1. 机器学习的流程与数据准备活动

机器学习始于数据。数据准备的典型活动（课件 p.2）：
1. 了解数据集中各属性的**类型**；
2. 探索数据，了解其性质和**质量**；
3. 探索数据元素之间的关系，例如特征之间的相关性；
4. 找出数据中的潜在**问题**（缺失值、离群点）；
5. 必要时做**修复（remediation）**，例如插补缺失值；
6. 做必要的**预处理**（缩放、降维）。

数据准备好之后：划分训练集和测试集（仅监督学习）→ 选择候选模型 → 训练 → 评估。

## 2. 数据类型（23-24 S1 Q2(a)，4 分）

**术语**：
- 数据集的每一行是一个 **sample（样本 / record）**；
- 每一列是一个 **attribute（属性）**，也叫 variable 或 feature。

| 大类 | 类型 | 定义 | 例子 | 能做的运算 / 统计量 |
|---|---|---|---|---|
| **Qualitative / Categorical（定性 / 类别）**：描述质量，不能测量 | **Nominal（名义）** | 只有名字，没有顺序 | 血型 A/B/O/AB、国籍、性别、学号 | 只能判断相等与否；**不能**加减乘除，不能算 mean、variance；集中趋势用 **mode** |
| | **Ordinal（有序）** | 有自然顺序，但等级间隔没有意义 | 满意度（Happy/Unhappy）、成绩等级 A/B/C、金属硬度（很硬/硬/软） | 可以排序，有 **median、quartiles**；**仍不能**算 mean |
| **Quantitative / Numeric（定量 / 数值）**：可以测量 | **Interval（区间）** | 顺序和差值都有意义，但**没有真正的零点** | 摄氏温度、日期、时刻 | 可以加减；mean、median、mode、标准差都能算；**不能算比值**（20°C 不是 10°C 的"两倍热"） |
| | **Ratio（比率）** | 有**绝对零点**，可以精确测量 | 身高、体重、价格、开尔文温度、年龄 | 加减乘除都可以；所有统计量都能算 |

**按取值个数分**：
- **Discrete（离散）**：有限个或**可数无限**（countably infinite）个取值。
  - 例如学号、邮编（有限个）；计数、班级排名（可数无限）。
  - **Binary（二值）**属性是特殊的离散属性：yes/no、正/负。
- **Continuous（连续）**：可以取任意实数值，例如长度、身高、体重、价格。
- 课件的概括："nominal and ordinal attributes are discrete; interval and ratio attributes are continuous"。数值型也有离散的，例如气缸数、计数。

**易错点**：
1. 学号、邮编虽然是数字，但属于 **nominal**，求平均没有意义。
2. 摄氏温度是 interval，开尔文温度是 ratio。
3. 气缸数（cylinders）、产地（origin）这类取值很少的数值属性，课件说可以当作类别属性处理。

## 3. 探索数值数据

### 3.1 集中趋势（central tendency）

| 统计量 | 定义 | 特点 |
|---|---|---|
| **Mean（均值）** | 所有值之和 / 个数。例：$(21 + 89 + 34 + 67 + 96)/5 = 61.4$ | **对离群点敏感** |
| **Median（中位数）** | 排序后中间那个值。例：21, 34, 67, 89, 96 → 67 | 对离群点稳健 |
| **Mode（众数）** | 出现次数最多的值。例：13, 13, 13, 13, 14, 14, 16, 18, 21 → 13 | 主要用于类别属性 |

**mean 和 median 差得很大时**，说明可能有离群点或偏态，要查原因。课件 Auto MPG 例子里：
- cylinders、displacement、origin 的均值和中位数偏差明显；
- horsepower 根本算不出均值，因为有 6 个缺失值。

### 3.2 离散程度（dispersion）

$$\mathrm{var}(X) = \frac1N\sum_{k=1}^N x^2(k) - \left(\frac1N\sum_{k=1}^N x(k)\right)^2,\qquad \sigma(X) = \sqrt{\mathrm{var}(X)}$$

课件用 $1/N$，即总体方差。

例子：
- 属性 1 = 44, 46, 48, 45, 47 → $\mathrm{var} = 2$，很集中；
- 属性 2 = 34, 46, 59, 39, 52 → $\mathrm{var} = 79.6$，很分散。

### 3.3 位置：五数概括与四分位数

- **$Q_2$** = 整体中位数；
- **$Q_1$** = 前半部分的中位数；
- **$Q_3$** = 后半部分的中位数。
- **五数概括（five-number summary）**：minimum、$Q_1$、$Q_2$、$Q_3$、maximum。

### 3.4 箱线图（box plot）与 IQR

- 箱子从 $Q_1$ 到 $Q_3$，中间的线是中位数。$IQR = Q_3 - Q_1$（inter-quartile range，四分位距）。
- **下须**：伸到 $Q_1 - 1.5\,IQR$ 以内**最小的数据值**。
- **上须**：伸到 $Q_3 + 1.5\,IQR$ 以内**最大的数据值**。
- 须线之外的点就是**离群点（outliers）**。

课件例子：$Q_1 = 73$、$Q_3 = 79$、$IQR = 6$。
- 下栅栏 $73 - 9 = 64$。数据里有 70、63、60，下须落在 70，63 和 60 是离群点。
- 上栅栏 $79 + 9 = 88$。数据里有 82、84、89，上须落在 84，89 是离群点。

> **看图（课件 p.33–p.35）**：箱线图的组成和两根须线的位置。

![课件 Slides2 p.33–p.35](figs/rg/s2_p33_p35.png)

**手算例子**：12 个值 52, 55, 57, 58, 60, 61, 62, 63, 65, 66, 70, 85（已排序）。

| 步骤 | 计算 |
|---|---|
| $Q_2$ | 第 6、7 个的平均 $= (61 + 62)/2 = \mathbf{61.5}$ |
| $Q_1$ | 前 6 个 {52, 55, 57, 58, 60, 61} 的中位数 $= (57 + 58)/2 = \mathbf{57.5}$ |
| $Q_3$ | 后 6 个 {62, 63, 65, 66, 70, 85} 的中位数 $= (65 + 66)/2 = \mathbf{65.5}$ |
| $IQR$ | $65.5 - 57.5 = \mathbf{8}$ |
| 栅栏 | 下 $57.5 - 12 = \mathbf{45.5}$；上 $65.5 + 12 = \mathbf{77.5}$ |
| 须线 | 下须 = $\ge 45.5$ 的最小值 **52**；上须 = $\le 77.5$ 的最大值 **70** |
| 离群点 | **85** |
| 对照 | 均值 62.83，比中位数 61.5 高，被 85 拉高了 |

### 3.5 其他探索工具

- **Histogram（直方图）**：把数值分成若干区间（bin），看分布形状：均匀、单峰、双峰、左偏、右偏。
- **类别数据**：手段有限，主要是统计每个取值出现的次数。
- **变量之间的关系**：
  - **scatter plot（散点图）**：看特征与目标、特征与特征的相关性，发现冗余特征和无用特征；
  - **two-way cross-tabulation（交叉表 / contingency table）**：看两个类别属性的联合频数。

## 4. 数据质量与修复

两类常见问题：
1. **Missing values（缺失值）**：某些数据元素没有值。
2. **Outliers（离群点）**：值和其他元素差别大得出奇。

**成因**：样本集选取不当（例如合并不同来源、不同时期的数据集）；数据采集出错（例如单位写错）。

### 4.1 离群点的处理（23-24 S1 Q2(b)，7 分）

**检测**：
- 箱线图 / **IQR 规则**：小于 $Q_1 - 1.5\,IQR$ 或大于 $Q_3 + 1.5\,IQR$；
- **z-score**：$\lvert z\rvert > 3$；
- 散点图、直方图；
- 基于距离或密度的方法（例如 DBSCAN 的噪声点）；
- 均值和中位数偏差大也是一个信号。

**处理**（课件 p.44–p.45）：

| 方法 | 做法 | 适用 |
|---|---|---|
| **Remove（删除）** | 直接删除离群样本 | 离群点不多、确认是错误时 |
| **Imputation（插补）** | 用 mean / median / mode 替换。也可以用**最相似样本**的 mean / median / mode | 想保留样本 |
| **Capping（截尾）** | 超出 $1.5\,IQR$ 范围的值，替换成第 5 或第 95 百分位数的值 | 保留样本但压住极端值 |
| **Treat separately（分开建模）** | 离群点数量很多时，可能代表另一种模式，把数据当成两个数据集分别建模 | 例如高血压人群 |
| **Keep（保留）** | 离群点是**自然的**（有合理原因），**不应修改** | 欺诈检测、故障诊断中离群点本身就是关注对象 |

**补充**：
- 先判断成因：错误数据能改就改，改不了就删；真实的极端值要慎重。
- 也可以用对数变换压缩长尾，或者改用稳健方法：用中位数代替均值、用决策树这类对离群点不敏感的模型。

### 4.2 缺失值的处理（23-24 S1 Q2(c)，7 分）

| 方法 | 做法 | 优缺点 / 条件 |
|---|---|---|
| **Eliminate samples（删除样本）** | 删掉有缺失值的样本 | 缺失比例在可容忍范围内、删完还剩足够多样本时可用。例：Auto MPG 398 个样本中 6 个缺 horsepower，删掉还剩 392 个。缺失比例很高时不行；缺失不是随机发生时会引入偏差 |
| **Impute（插补）：整体统计量** | 数值属性用该属性其余值的 **mean / median / mode**；类别属性用 **mode** | 简单；但会低估方差、削弱特征间相关性。有离群点时用 median |
| **Impute：相似样本的统计量** | 先找"同类"样本，用它们的 mean / median。例：horsepower 缺失时按 cylinders 分组，4 缸车用 4 缸车的平均 horsepower，6 缸车用 6 缸车的 | 比整体均值更准 |
| **Estimate（估计）** | 用距离函数找最相似的样本，把它们的值填过来。例：一个 12 岁、身高 5 英尺的俄罗斯学生缺体重，就用年龄、身高相近的俄罗斯学生的体重。也可以用其他相关特征建回归模型预测（老师讲的 $x_1 = f(x_2)$） | 最准，计算量最大 |

**补充**：
- 某个特征缺失比例非常高时，可以直接删掉这个特征；
- 可以加一个"是否缺失"的指示变量；
- **插补用的统计量只能从训练集计算**，避免信息泄露到测试集。

> **看图（课件 p.46、p.48、p.50）**：删除样本、用 mean / median / mode 插补、按 cylinders 分组的相似样本插补。

![课件 Slides2 p.46、p.48、p.50](figs/rg/s2_p46_p48_p50.png)

**小例子**：身高（cm）。男：175, 180, ?, 172, 178；女：160, ?, 165, 158。

| 插补方式 | 男生缺失值 | 女生缺失值 |
|---|---|---|
| 整体均值（7 个已知值） | 169.71 | 169.71 |
| 整体中位数 | 172 | 172 |
| **按性别分组的均值** | **176.25** | **161.0** |
| 按性别分组的中位数 | 176.5 | 160 |

用整体均值会让女生身高被高估约 9 cm。按性别分组插补更合理，这就是课件说的 "similar types of observations"。

## 5. 特征缩放（23-24 S1 Q2(d)，7 分；总复习 p.1 给了公式）

### 5.1 为什么要缩放

**Feature scaling（特征缩放）**把各特征变换到相近的尺度，让各特征对模型的贡献相当，避免**取值大的特征主导模型**。

1. **基于距离的算法**（KNN、K-means、层次聚类、SVM、LDA 等）受影响最大。
   - 课件例子：CGPA（0–5）和收入（千元）。缩放前，学生 1、2 的距离 20 几乎完全来自收入差（60 − 40）；学生 2、3 只差 CGPA 1 分，距离是 1。
   - 缩放后两个距离变成 2.6 和 1.59，CGPA 的差别才被正确地计入。
2. **基于梯度下降的算法**：更新量
   $$\theta_i(k+1) = \theta_i(k) - \eta\,\frac{\partial L(k)}{\partial\theta_i(k)}$$
   与 $x_i$ 成比例。尺度差别大时，不同参数的步长差别很大。尺度相近时收敛更快、更稳定。

不需要缩放的：决策树、随机森林这类按阈值划分的模型对尺度不敏感。

> **看图（课件 p.53–p.55）**：CGPA 与收入的例子，缩放前后的距离对比。

![课件 Slides2 p.53–p.55](figs/rg/s2_p53_p55.png)

### 5.2 两种方法

| | **Normalization（归一化，Min-Max scaling）** | **Standardization（标准化，z-score）** |
|---|---|---|
| 公式 | $x' = \dfrac{x - x_{min}}{x_{max} - x_{min}}$ | $x' = \dfrac{x - \mu}{\sigma}$ |
| 结果 | 落在 $[0, 1]$ | 均值 0、标准差 1，**不限定范围** |
| 优点 | 有明确范围，保留原始分布形状 | 对离群点相对稳健；适合近似高斯的数据，是 SVM、LDA、PCA 的常用预处理 |
| 缺点 | **对离群点敏感**：一个极端值会把其他值挤到很窄的区间里 | 结果没有固定上下界 |
| 适合 | 数据有明确边界（如图像像素 0–255） | 数据近似正态、有离群点 |

**注意**：
- 课件计算 $\sigma$ 用的是 $1/N$（总体标准差），课件 p.54 的数值就是这样算的。
- 缩放参数（min、max 或 $\mu$、$\sigma$）**只从训练集估计**，再用同一组参数去变换测试集。

**手算例子**：4 个样本（工作年限 $x_1$，年薪 $x_2$ 千元）：A(2, 40)、B(10, 44)、C(3, 52)、D(6, 70)。

| | $x_1$ 原值 | $x_2$ 原值 | $x_1$ min-max | $x_2$ min-max | $x_1$ z-score | $x_2$ z-score |
|---|---|---|---|---|---|---|
| A | 2 | 40 | 0 | 0 | −1.0442 | −0.9981 |
| B | 10 | 44 | 1 | 0.1333 | 1.5261 | −0.6509 |
| C | 3 | 52 | 0.125 | 0.4 | −0.7229 | 0.0434 |
| D | 6 | 70 | 0.5 | 1 | 0.2410 | 1.6057 |

- min-max：$x_1$ 范围 2–10，$x_2$ 范围 40–70。例如 B 的 $x_2' = (44 - 40)/30 = 0.1333$。
- z-score：$x_1$ 的 $\mu = 5.25$、$\sigma = 3.1125$；$x_2$ 的 $\mu = 51.5$、$\sigma = 11.5217$。例如 A 的 $x_1' = (2 - 5.25)/3.1125 = -1.0442$。

| 距离 | 原始 | min-max | z-score |
|---|---|---|---|
| $d(A, B)$ | $\sqrt{64 + 16} = \mathbf{8.94}$ | 1.009 | 2.594 |
| $d(A, C)$ | $\sqrt{1 + 144} = \mathbf{12.04}$ | **0.419** | **1.090** |

## 6. 回归问题与线性回归模型

- **Classification（分类）**：目标变量是**类别**（normal / abnormal）。
- **Regression（回归）**：目标变量是**数值**（股价、需求量）。
- 两者都是**监督学习**。

**Simple linear regression（一元线性回归）**：

$$y = \theta_0 + \theta_1x + \varepsilon$$

- $y$：target / dependent variable（目标 / 因变量）；
- $x$：predictor / independent variable（预测 / 自变量）；
- $\theta_0$：intercept（截距）；$\theta_1$：slope（斜率）；$\varepsilon$：residual / error（残差）。

**Multiple linear regression（多元线性回归）**：

$$y = \theta_0 + \theta_1x_1 + \cdots + \theta_mx_m + \varepsilon$$

## 7. Ordinary Least Squares（OLS，普通最小二乘）

### 7.1 推导（课件 p.4–p.7）

$N$ 个训练样本 $(x_i, y_i)$，$x_i = [x_{i1}, \dots, x_{im}]$。每个样本：$y_i = [1, x_{i1}, \dots, x_{im}]\,\theta + \varepsilon_i$。写成矩阵：

$$y = \Phi\theta + \varepsilon,\qquad
y = \begin{bmatrix}y_1\\ \vdots\\ y_N\end{bmatrix},\quad
\Phi = \begin{bmatrix}1 & x_{11} & \cdots & x_{1m}\\ \vdots & \vdots & & \vdots\\ 1 & x_{N1} & \cdots & x_{Nm}\end{bmatrix},\quad
\theta = \begin{bmatrix}\theta_0\\ \vdots\\ \theta_m\end{bmatrix}$$

- $\Phi$ 是 $N \times (m+1)$ 矩阵，**第一列全是 1，对应截距**。

**损失函数**：

$$J(\theta) = \frac12\sum_{i=1}^N\varepsilon_i^2 = \frac12(y - \Phi\theta)^T(y - \Phi\theta)$$

**求解**：令 $\dfrac{\partial J}{\partial\theta} = -\Phi^T(y - \Phi\theta) = 0$，得到正规方程 $\Phi^T\Phi\,\theta = \Phi^Ty$，所以

$$\hat\theta = (\Phi^T\Phi)^{-1}\Phi^Ty$$

因为它使平方误差最小，所以叫 ordinary least squares estimation。

> **看图（课件 p.5–p.7）**：矩阵形式、损失函数、求导和闭式解。

![课件 Slides8 p.5–p.7](figs/rg/s8_p5_p7.png)

### 7.2 手算例子

$x = [1, 2, 3, 4, 5]$，$y = [2, 3, 5, 4, 6]$。

- $\Phi$ 的每一行是 $[1, x_i]$：
  $$\Phi^T\Phi = \begin{bmatrix}N & \sum x\\ \sum x & \sum x^2\end{bmatrix} = \begin{bmatrix}5 & 15\\ 15 & 55\end{bmatrix},\qquad \Phi^Ty = \begin{bmatrix}\sum y\\ \sum xy\end{bmatrix} = \begin{bmatrix}20\\ 69\end{bmatrix}$$
- $\det = 5\times 55 - 15^2 = 50$；$(\Phi^T\Phi)^{-1} = \dfrac{1}{50}\begin{bmatrix}55 & -15\\ -15 & 5\end{bmatrix}$。
- $\hat\theta_0 = \dfrac{55\times 20 - 15\times 69}{50} = \dfrac{1100 - 1035}{50} = \mathbf{1.3}$。
- $\hat\theta_1 = \dfrac{-15\times 20 + 5\times 69}{50} = \dfrac{-300 + 345}{50} = \mathbf{0.9}$。
- 模型：$\hat y = 1.3 + 0.9x$。

| $x$ | $y$ | $\hat y$ | 残差 $y - \hat y$ |
|---|---|---|---|
| 1 | 2 | 2.2 | −0.2 |
| 2 | 3 | 3.1 | −0.1 |
| 3 | 5 | 4.0 | 1.0 |
| 4 | 4 | 4.9 | −0.9 |
| 5 | 6 | 5.8 | 0.2 |

- 残差之和为 0。这是有截距的 OLS 的性质，可以用来自检。
- $RSS = 0.04 + 0.01 + 1 + 0.81 + 0.04 = \mathbf{1.9}$。

> **看图 2-1**：红线是 OLS 拟合直线，绿色虚线是残差，灰色点线是 $\bar y = 4$。OLS 让绿线长度的平方和最小。

![图 2-1](figs/rg/fig1_ols_example.png)

> **看图（课件 p.10–p.12）**：200 个样本的例子，OLS 得到 $\theta = [0.4433, 2.0728]$，真值是 $[0.5, 2]$。噪声标准差降到 0.5、0.1、0 时，估计越来越接近真值，无噪声时恰好得到 $[0.5, 2.0]$。

## 8. Ridge regression（岭回归，L2 正则化）

### 8.1 OLS 的三个问题（课件 p.13）

1. 自变量个数远多于样本数时，OLS 解**不唯一**。
2. $\Phi$ **病态（ill-conditioned）**：OLS 依赖 $(\Phi^T\Phi)^{-1}$，$\Phi^T\Phi$ 奇异或接近奇异时，逆矩阵不存在或数值极不稳定。例如两个特征高度相关时就会这样，这和专题 01 里高维小样本下 $S_W$ 不可逆是同一个问题。
3. 在训练集上拟合得好，但**泛化差**（过拟合）。

### 8.2 公式

$$J_{ridge}(\theta) = \frac12\left[\sum_{i=1}^N(\hat y_i - y_i)^2 + \lambda\sum_{j=0}^m\theta_j^2\right] = \frac12\left[(y - \Phi\theta)^T(y - \Phi\theta) + \lambda\,\theta^T\theta\right]$$

令梯度为 0：

$$\hat\theta_{ridge} = (\Phi^T\Phi + \lambda I)^{-1}\Phi^Ty$$

$I$ 是 $(m+1)\times(m+1)$ 单位矩阵，$\lambda > 0$。

- 加上 $\lambda I$ 后矩阵一定可逆，解决了问题 1 和 2。
- 惩罚的是参数向量的 **L2 范数平方**。参数大时目标函数被罚，所以 Ridge 把参数**向 0 收缩（shrink）**，但一般**不会恰好等于 0**。
- 这是 **regularization（正则化）**：在拟合误差之外加一个惩罚项，以略微增大训练误差为代价，换取测试集上更小的方差，避免过拟合。
- 课件公式的求和从 $j = 0$ 开始，所以截距也被惩罚。很多教材和软件不惩罚截距。

**接 §7.2 的例子，取 $\lambda = 1$**：
- $\Phi^T\Phi + I = \begin{bmatrix}6 & 15\\ 15 & 56\end{bmatrix}$，$\det = 336 - 225 = 111$；
- $\hat\theta_0 = \dfrac{56\times 20 - 15\times 69}{111} = \dfrac{85}{111} = \mathbf{0.7658}$；
- $\hat\theta_1 = \dfrac{-15\times 20 + 6\times 69}{111} = \dfrac{114}{111} = \mathbf{1.0270}$。

**对比**：
- $\lVert\theta\rVert^2$ 从 OLS 的 $1.3^2 + 0.9^2 = 2.50$ 降到 $0.7658^2 + 1.0270^2 = \mathbf{1.64}$，整体被收缩了；
- 截距被压小，斜率反而变大一点。收缩是对整个向量而言的，不是每个分量都变小。
- 训练 RSS 从 1.9 升到 2.18，这是正则化付出的代价。

> **看图（课件 p.13–p.15）**：OLS 的三个问题、Ridge 的公式和解，以及正则化的概念。

![课件 Slides8 p.13–p.15](figs/rg/s8_p13_p15.png)

## 9. Lasso regression（L1 正则化）

**Lasso = Least Absolute Shrinkage and Selection Operator。**

$$J_{lasso}(\theta) = \frac12\left[\sum_{i=1}^N(\hat y_i - y_i)^2 + \lambda\sum_{j=0}^m\lvert\theta_j\rvert\right] = \frac12\left[(y - \Phi\theta)^T(y - \Phi\theta) + \lambda\lVert\theta\rVert_1\right]$$

- L1 范数 $\lVert\theta\rVert_1 = \sum_j\lvert\theta_j\rvert$（Manhattan 范数）；L2 范数 $\lVert\theta\rVert_2 = \sqrt{\sum_j\theta_j^2}$（欧氏范数）。
- **核心区别**：Lasso 会把最不重要的自变量的系数**压缩到恰好为 0**，相当于把这些变量从模型中删掉，得到 **sparse model（稀疏模型）**。
  - 所以 Lasso **自带特征选择**，是专题 05 里 embedded 方法的代表。
- **没有解析解**：$\lvert\theta\rvert$ 在 0 处不可导，要用数值算法迭代求解，实际中直接调用工具箱。
- **$\lambda$ 的选择至关重要**：
  - $\lambda$ 大 → 正则化强，更多系数变成 0，可能欠拟合；
  - $\lambda$ 小 → 更多变量保留非零系数，可能过拟合；
  - $\lambda$ 是超参数，用验证集或交叉验证选。

**为什么 L1 会产生 0**（两种解释）：
1. **老师的数值解释**：对 $\theta = 0.1$，L2 惩罚 $\theta^2 = 0.01$，几乎不罚；L1 惩罚 $\lvert\theta\rvert = 0.1$，罚得相对重。所以 L1 会继续把小系数往 0 推，L2 推到很小就不再用力了。
2. **几何解释**：
   - 带约束的形式是：最小化误差，约束 $\sum\lvert\theta_j\rvert \le t$（菱形）或 $\sum\theta_j^2 \le t$（圆）；
   - 误差的椭圆等高线向外扩张，第一次碰到约束区域的点就是解；
   - 菱形有尖角落在坐标轴上，等高线很容易先碰到尖角，那里有一个坐标恰好为 0；
   - 圆没有尖角，切点一般两个坐标都不为 0。

> **看图 4-2**：左边是 Ridge，切点 $(0.96, 0.29)$ 两个系数都非零；右边是 Lasso，切点正好在菱形顶点 $(1, 0)$，$\theta_2 = 0$。

> **看图 4-1**：8 个特征里真正有用的只有 3 个（实线）。
> - 左：Ridge 随 $\lambda$ 增大，所有系数平滑地一起缩向 0，但都不为 0。
> - 右：Lasso 随 $\lambda$ 增大，无用特征（虚线）很早就变成 0，有用的系数最后才被压到 0。
> - 两个高度相关的特征 $\theta_1$、$\theta_2$ 在 Lasso 里会出现"保留一个、压掉另一个"的现象。

![图 4-1](figs/rg/fig2_coef_paths.png)

### Ridge vs Lasso 对比表（论述题直接用）

| | Ridge | Lasso |
|---|---|---|
| 惩罚项 | $\lambda\sum\theta_j^2$（L2 范数的平方） | $\lambda\sum\lvert\theta_j\rvert$（L1 范数） |
| 系数 | 向 0 收缩，一般不为 0 | 不重要的系数**恰好为 0** |
| 特征选择 | 没有，所有变量都保留 | **有**，得到稀疏模型 |
| 解 | **解析解** $(\Phi^T\Phi + \lambda I)^{-1}\Phi^Ty$ | **没有解析解**，要数值迭代 |
| 相关特征 | 把权重分摊到相关特征上 | 倾向保留其中一个 |
| 共同点 | 都是正则化，防止过拟合、处理 $\Phi^T\Phi$ 病态；$\lambda$ 越大收缩越强；$\lambda$ 用验证集选 | |

## 10. 回归模型的评价指标（课件 p.20–p.31）

$\hat y_i$ 是预测值，$y_i$ 是真实值，$N$ 是样本数，$m$ 是自变量个数。

| 指标 | 公式 | 说明 |
|---|---|---|
| **MSE** | $\dfrac1N\sum_{i=1}^N(\hat y_i - y_i)^2$ | 越小越好；对大误差惩罚重；可导，常用作损失函数 |
| **RMSE** | $\sqrt{\text{MSE}}$ | 越小越好；**与因变量同单位**，比 MSE 更常用；比较不同回归模型时比 $R^2$ 更合适 |
| **MAE** | $\dfrac1N\sum_{i=1}^N\lvert\hat y_i - y_i\rvert$ | 越小越好；对离群点不如 MSE 敏感；在 0 处不可导 |
| **$R^2$** | $1 - \dfrac{RSS}{TSS}$，$RSS = \sum(\hat y_i - y_i)^2$，$TSS = \sum(\bar y - y_i)^2$ | 被模型解释的方差比例，在 0 到 1 之间（训练集上、有截距时），**越大越好** |
| **Adjusted $R^2$** | $1 - \dfrac{(1 - R^2)(n - 1)}{n - m - 1}$ | 惩罚无用变量 |

**$R^2$ 的缺陷**：
- 加入任何变量（哪怕毫无用处），训练集上的 $R^2$ 都**只增不减**。所以 $R^2$ 高不代表模型好，可能只是变量多。
- **Adjusted $R^2$** 考虑了变量个数，只有新变量带来的改善足够大时才会上升，适合做模型选择。

**接 §7.2 的例子**（$n = 5$，$m = 1$）：
- $\bar y = 4$，$TSS = 4 + 1 + 1 + 0 + 4 = 10$；$RSS = 1.9$。
- $R^2 = 1 - 1.9/10 = \mathbf{0.81}$。
- $\text{Adjusted } R^2 = 1 - 0.19\times\dfrac43 = \mathbf{0.7467}$。
- $\text{MSE} = 1.9/5 = \mathbf{0.38}$，$\text{RMSE} = \mathbf{0.6164}$，$\text{MAE} = \dfrac{0.2 + 0.1 + 1 + 0.9 + 0.2}{5} = \mathbf{0.48}$。

## 11. 回归模型的检验：五个假设（课件 p.32–p.38）

1. **Linear relationship（线性关系）**：因变量与自变量是线性关系。检查方法：画"实际值 vs 预测值"散点图，点应沿对角线分布。
2. **残差服从正态分布**：画残差直方图或 **Q-Q plot**（样本分位数 vs 正态理论分位数，应近似一条直线）。
3. **残差均值为 0 或接近 0**：课件例子的残差均值是 $2.05\times 10^{-17} \approx 0$。
4. **所有自变量服从多元正态分布**。
5. **Homoscedasticity（同方差）**：残差的大小不随自变量（或预测值）变化。
   - 违反时叫 **heteroscedasticity（异方差）**。
   - 检查方法：画"残差 vs 预测值"散点图，出现漏斗形（funnel shape）就说明违反了。

## 12. 论述题范文（英文，可直接写）

### E1. Data types in machine learning（4 分，23-24 S1 Q2(a)）
（机器学习中的数据类型。）

> Data are either **qualitative (categorical)** or **quantitative (numeric)**. Qualitative data describe qualities that cannot be measured: **nominal** data are named values without order, e.g., blood group, nationality, gender, where no arithmetic is meaningful and only the mode can describe the central tendency; **ordinal** data can be naturally ordered, e.g., grades A/B/C or customer satisfaction, so median and quartiles exist but the mean cannot be computed. Quantitative data can be measured: **interval** data have meaningful order and differences but no true zero, e.g., Celsius temperature and dates, so addition, subtraction, mean and standard deviation apply but ratios do not; **ratio** data have an absolute zero, e.g., height, weight, price, so all arithmetic operations, including ratios, are valid. Attributes can also be discrete (finite or countably infinite values, including binary attributes) or continuous (any real value).

> 【中文】数据分为**定性（类别型）**和**定量（数值型）**两种。定性数据描述无法测量的性质：**名义型**数据是没有顺序的命名值，如血型、国籍、性别，任何算术运算都没有意义，只能用众数描述集中趋势；**序数型**数据可以自然排序，如成绩 A/B/C 或客户满意度，可以求中位数和四分位数，但不能算均值。定量数据可以测量：**区间型**数据的顺序和差值有意义，但没有绝对零点，如摄氏温度和日期，可以做加减、求均值和标准差，但比值没有意义；**比率型**数据有绝对零点，如身高、体重、价格，所有算术运算包括比值都成立。属性还可以分为离散（有限或可数无限个取值，包括二值属性）和连续（任意实数值）。

### E2. How to handle outliers（7 分，23-24 S1 Q2(b)）
（如何处理离群点。）

> **Definition and detection.** Outliers are samples with abnormally high or low values, caused by errors in data collection (e.g., wrong units), incorrect sample selection, or genuine rare cases. They distort the mean, variance and model parameters and affect distance-based algorithms. They can be detected with a box plot or the IQR rule (values below $Q_1 - 1.5\,IQR$ or above $Q_3 + 1.5\,IQR$), with z-scores ($\lvert z\rvert > 3$), with scatter plots and histograms, or by a large gap between mean and median.
>
> **Handling.** (1) **Remove** them if they are few and known to be errors. (2) **Impute** them with the mean, median or mode, or with the statistics of the most similar samples. (3) **Cap** values outside the $1.5\,IQR$ limits, replacing them with the 5th or 95th percentile. (4) If there are many outliers, they may represent a different pattern, so **model them separately** as a second data set. (5) If the outliers are **natural**, i.e., have a valid reason, they should **not be amended**, e.g., in fraud or fault detection the outliers are what we look for. Robust alternatives, such as using the median, log transforms or tree-based models, also reduce their influence.

> 【中文】
> **定义与检测。** 离群点是取值异常高或异常低的样本，成因可能是数据采集错误（如单位错误）、样本选择不当，也可能是真实的罕见情况。它们会扭曲均值、方差和模型参数，影响基于距离的算法。可以用箱线图或 IQR 规则（小于 Q₁ − 1.5·IQR 或大于 Q₃ + 1.5·IQR）、z-score（|z| > 3）、散点图和直方图检测，均值和中位数相差很大也是信号。
>
> **处理。** (1) 如果离群点少且确认是错误，就**删除**。(2) 用均值、中位数或众数**插补**，或用最相似样本的统计量插补。(3) **截尾**：超出 1.5·IQR 范围的值换成第 5 或第 95 百分位数。(4) 离群点很多时，可能代表另一种模式，就作为第二个数据集**分开建模**。(5) 如果离群点是**自然的**，即有合理原因，就**不应修改**，例如欺诈检测或故障检测中，离群点正是要找的对象。使用中位数、对数变换或树模型等稳健方法，也能减小离群点的影响。

### E3. How to handle missing values（7 分，23-24 S1 Q2(c)）
（如何处理缺失值。）

> (1) **Eliminate samples with missing values**, which is simple and effective if the proportion of such samples is tolerable and enough data remain (e.g., 6 of 398 samples in the Auto MPG data); it is not possible when the proportion is high, and may bias the data if values are not missing at random. A feature with a very high missing rate may be dropped instead. (2) **Impute with a statistic of the remaining values of the same attribute**: mean, median or mode for quantitative attributes (median if outliers exist), and mode for qualitative attributes; this is easy but reduces variance. (3) **Impute with the statistics of similar observations**, e.g., the mean horsepower of cars with the same number of cylinders, which is more accurate. (4) **Estimate the missing value** from the most similar data points found with a distance function, or predict it from correlated features with a regression model; this is the most accurate but costs more computation. Imputation statistics must be computed on the training data only.

> 【中文】(1) **删除含缺失值的样本**：如果这类样本的比例可以容忍、删完还剩足够数据（如 Auto MPG 数据 398 个样本中的 6 个），这种做法简单有效；比例高时不可行，缺失不是随机发生时还会使数据产生偏差。缺失率非常高的特征也可以直接删掉。(2) **用同一属性其余值的统计量插补**：数值属性用均值、中位数或众数（有离群点时用中位数），类别属性用众数；简单，但会降低方差。(3) **用相似观测的统计量插补**，例如用相同缸数汽车的平均马力，更准确。(4) **估计缺失值**：用距离函数找到最相似的数据点，或者用相关特征建回归模型来预测；最准确，但计算量更大。插补用的统计量只能从训练数据计算。

### E4. Features with different ranges: normalization and standardization（7 分，23-24 S1 Q2(d)）
（特征取值范围不同：归一化与标准化。）

> **Why.** Features with large values dominate distance computations, so distance-based algorithms (KNN, K-means, hierarchical clustering, SVM) would effectively ignore small-scale features; in gradient-descent-based learning, very different feature ranges cause very different update steps for the parameters, slowing or destabilizing convergence. Feature scaling makes all features contribute comparably.
>
> **Normalization (min-max scaling):** $x' = \dfrac{x - x_{min}}{x_{max} - x_{min}}$, which maps values into $[0, 1]$ and preserves the shape of the distribution, but is sensitive to outliers, since one extreme value compresses all others into a narrow range. **Standardization (z-score):** $x' = \dfrac{x - \mu}{\sigma}$, which gives zero mean and unit standard deviation without bounding the range; it is less affected by outliers and suits roughly Gaussian data and methods such as SVM, LDA and PCA. The scaling parameters must be estimated on the training set and applied unchanged to the test set. Tree-based models are insensitive to feature scale.

> 【中文】
> **为什么。** 取值大的特征主导距离计算，所以基于距离的算法（KNN、K-means、层次聚类、SVM）实际上会忽略尺度小的特征；在基于梯度下降的学习中，特征范围差别很大会使各参数的更新步长差别很大，收敛变慢或不稳定。特征缩放让所有特征的贡献相当。
>
> **归一化（min-max 缩放）**：x' = (x − x_min)/(x_max − x_min)，把值映射到 [0, 1]，保留分布形状，但对离群点敏感，因为一个极端值会把其他值都挤到很窄的区间里。**标准化（z-score）**：x' = (x − μ)/σ，得到均值 0、标准差 1，但不限定范围；受离群点影响较小，适合近似高斯的数据以及 SVM、LDA、PCA 等方法。缩放参数必须在训练集上估计，再原样用到测试集上。树模型对特征尺度不敏感。

### E5. OLS estimation for multiple linear regression（6 分，可能的变体）
（多元线性回归的 OLS 估计。）

> The model is $y = \theta_0 + \theta_1x_1 + \cdots + \theta_mx_m + \varepsilon$. For $N$ training pairs, write $y = \Phi\theta + \varepsilon$, where $y = [y_1, \dots, y_N]^T$, the $i$-th row of $\Phi$ is $[1, x_{i1}, \dots, x_{im}]$, and $\theta = [\theta_0, \dots, \theta_m]^T$. OLS minimizes the sum of squared errors $J(\theta) = \tfrac12(y - \Phi\theta)^T(y - \Phi\theta)$. Setting $\partial J/\partial\theta = -\Phi^T(y - \Phi\theta) = 0$ gives the normal equations $\Phi^T\Phi\,\theta = \Phi^Ty$, so $\hat\theta = (\Phi^T\Phi)^{-1}\Phi^Ty$. The estimation error is caused by noise: the higher the noise level, the larger the error. OLS fails or becomes unstable when the number of predictors exceeds the number of samples or when $\Phi^T\Phi$ is singular or nearly singular, and it may overfit the training data.

> 【中文】模型为 y = θ₀ + θ₁x₁ + ⋯ + θₘxₘ + ε。对 N 个训练样本，写成 y = Φθ + ε，其中 y = [y₁, …, y_N]ᵀ，Φ 的第 i 行是 [1, x_{i1}, …, x_{im}]，θ = [θ₀, …, θₘ]ᵀ。OLS 最小化误差平方和 J(θ) = ½(y − Φθ)ᵀ(y − Φθ)。令 ∂J/∂θ = −Φᵀ(y − Φθ) = 0，得正规方程 ΦᵀΦθ = Φᵀy，所以 θ̂ = (ΦᵀΦ)⁻¹Φᵀy。估计误差由噪声引起：噪声越大，误差越大。当自变量个数超过样本数，或 ΦᵀΦ 奇异、接近奇异时，OLS 失效或不稳定，还可能对训练数据过拟合。

### E6. Compare ridge and lasso regression（6 分，可能的变体）
（比较岭回归和 Lasso 回归。）

> Both add a penalty on the parameter vector to the least-squares loss to regularize the model, reduce overfitting and handle an ill-conditioned $\Phi^T\Phi$. **Ridge** uses the squared L2 norm, $J = \tfrac12\left[\sum(\hat y_i - y_i)^2 + \lambda\sum\theta_j^2\right]$; it has the analytic solution $\theta = (\Phi^T\Phi + \lambda I)^{-1}\Phi^Ty$, always invertible for $\lambda > 0$, and shrinks all coefficients towards zero without making them exactly zero, so all variables stay in the model. **Lasso** uses the L1 norm, $J = \tfrac12\left[\sum(\hat y_i - y_i)^2 + \lambda\sum\lvert\theta_j\rvert\right]$; it shrinks the coefficients of the least important predictors exactly to zero, producing a sparse model and thus performing variable (feature) selection, but it has no analytic solution and must be solved numerically. In both, $\lambda$ controls the trade-off: a large $\lambda$ gives stronger shrinkage (risk of underfitting; for Lasso, more coefficients become zero), a small $\lambda$ approaches OLS (risk of overfitting). $\lambda$ is a hyperparameter chosen on validation data or by cross-validation.

> 【中文】两者都在最小二乘损失上加一个对参数向量的惩罚，以正则化模型、减轻过拟合、处理病态的 ΦᵀΦ。**Ridge** 用 L2 范数的平方，J = ½[Σ(ŷᵢ − yᵢ)² + λΣθⱼ²]；它有解析解 θ = (ΦᵀΦ + λI)⁻¹Φᵀy，λ > 0 时总是可逆，把所有系数向 0 收缩但不会恰好为 0，所以所有变量都留在模型中。**Lasso** 用 L1 范数，J = ½[Σ(ŷᵢ − yᵢ)² + λΣ|θⱼ|]；它把最不重要的自变量的系数压到恰好为 0，得到稀疏模型，从而完成变量（特征）选择，但没有解析解，必须数值求解。两者都由 λ 控制权衡：λ 大则收缩强（有欠拟合风险；对 Lasso 来说更多系数变成 0），λ 小则接近 OLS（有过拟合风险）。λ 是超参数，用验证数据或交叉验证选。

### E7. Evaluation metrics for regression; why adjusted R²（5 分）
（回归的评价指标；为什么要用调整 R²。）

> $\text{MSE} = \frac1N\sum(\hat y_i - y_i)^2$, $\text{RMSE} = \sqrt{\text{MSE}}$, and $\text{MAE} = \frac1N\sum\lvert\hat y_i - y_i\rvert$ measure prediction error; lower is better. MSE and RMSE penalize large errors more than MAE; RMSE has the same unit as the target and is preferred for comparing models; MSE is differentiable and commonly used as a loss function. $R^2 = 1 - RSS/TSS$ is the fraction of the variance of the target explained by the model; higher is better, and what is "good" depends on the application. Its flaw is that it never decreases when more variables are added, even useless ones. $\text{Adjusted } R^2 = 1 - \dfrac{(1 - R^2)(n - 1)}{n - m - 1}$ penalizes the number of predictors $m$ and increases only if a new variable improves the model sufficiently, so it is suitable for model selection.

> 【中文】MSE = (1/N)Σ(ŷᵢ − yᵢ)²、RMSE = √MSE 和 MAE = (1/N)Σ|ŷᵢ − yᵢ| 衡量预测误差，越小越好。MSE 和 RMSE 对大误差的惩罚比 MAE 重；RMSE 与目标变量同单位，比较模型时更常用；MSE 可导，常用作损失函数。R² = 1 − RSS/TSS 是模型解释的目标变量方差的比例，越大越好，多大算"好"取决于具体应用。它的缺陷是增加变量时从不下降，哪怕变量毫无用处。调整 R² = 1 − (1 − R²)(n − 1)/(n − m − 1) 对自变量个数 m 进行惩罚，只有新变量带来足够的改善时才会上升，所以适合做模型选择。
