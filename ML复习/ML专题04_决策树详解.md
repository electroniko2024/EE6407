### 0.2 老师在课上说过的话

1. **为什么要用树**（week10）：nominal feature（名义特征）比如交通方式，用 1、2、3、4 编号只是为了区分。"the Euclidean distance does not reflect the similarity"，基于距离的方法不再合适，要用 **non-metric method（非度量方法）**，分类树就是其中一种。
2. **基本原则是 simplicity（简单）**："we prefer decisions that lead to a simple, compact tree with few nodes."
3. **建树要回答五个问题**（课件 p.7）："answer these five questions, you are able to construct a classification tree."
4. **课件的 Gini 带 $\tfrac12$**："textbooks, articles, they don't include the half. But here we use the half. But this does not affect the result… just like a scaling factor."
5. **不同的 impurity 不能互相比较**：数值本身不同，"we cannot compare these two different measures"。评价时只能用同一种。
6. **考试会指定用哪种 impurity**（week13 总复习）："in the exam… you will be instructed in the question" 用 entropy 还是 Gini。
7. **怎么选特征**："we should try one by one, because we don't know which feature is a good feature"。每个特征、每个取值都试一遍，选使 children node（子节点）不纯度最小的那个。
8. **连续特征**：先排序，相邻两值取中点作为候选分割点，"we try each of these values"。
9. **加权**：两个子节点的不纯度要加权求和，"the weightage is simply the proportion of the data going to this branch"。
10. **两阶段**：先 grow（长树），再 prune（剪枝），"we first grow and then we cut the branch"。
11. **随机森林有两处随机**（week13 原话大意）：每棵树用 bootstrap 抽的样本子集，加上随机选的特征子集。目的是 "reduce the correlation between the different trees"，得到 diversity（多样性）。老师说 "diversity is very important"。
12. **Bootstrap = sampling with replacement（有放回抽样）**：老师举了从 50 个学生里抽 10 个、抽完放回的例子；所以子集里 "some sample may be repeated"。

## 1. 为什么需要分类树

前面学的 LDA、SVM、Bayes，都默认特征是实数，样本之间的 **distance（距离）**有意义。例如两个向量的欧氏距离越小，两个样本越像。

但有些特征是 **nominal data（名义数据）**，只是名字或标签，没有大小：
- transportation mode（交通方式）：train、car、air、sea；
- colour（颜色）：red、yellow、blue、green。

如果编成 1、2、3、4 再算欧氏距离，"car 和 sea 的距离是 car 和 train 的两倍"这种说法毫无意义。这时用 **non-metric method（非度量方法）**，分类树就是代表。

**分类树的优点：interpretability（可解释性）**，有两层意思：
1. 决策过程可以直接读出来：一串 if–then 规则；
2. 可以很自然地加入专家的 **prior knowledge（先验知识）**。

> **看图（下图左，课件 p.3）**：水果分类树。最上面是 **root node（根节点）**，问 "color = green?"。每个椭圆是一个问题，连线是 **branch（分支）**，最下面带水果名的是 **leaf node（叶节点）**。一个样本从根往下回答一连串 yes/no 问题，落到哪个叶子就判成哪类。
> **看图（下图右，课件 p.9）**：属性 CP 有 1–4 四个取值。上面是两种 **binary split（二叉划分）**：$\text{CP} > 2$? 和 $\text{CP} = 1$?。下面是两种 **multiple split（多叉划分）**。

## 2. 术语

| 英文 | 中文 | 含义 |
|---|---|---|
| root node | 根节点 | 第一个问题，划分全部训练数据 |
| internal / descendent node | 内部 / 后代节点 | 继续划分到达它的数据子集 |
| leaf node | 叶节点 | 不再划分，带一个类别标签 |
| branch / link | 分支 | 问题的一个答案 |
| branching factor (ratio) | 分支因子 | 一个节点往下分几支，由设计者决定 |
| binary tree | 二叉树 | 每个节点都只分两支；**CART** 就是二叉树 |
| property test / query | 属性测试 / 问题 | 节点上问的问题，例如 "$x_2 < 1.3271$?" |

问题的形式只有三种：yes/no、true/false，或 "value(property) $\in$ set of values"（属性值是否属于某个集合）。

## 4. Impurity（不纯度）的四种度量

我们希望划分后每个子节点尽量 "pure"（纯）：只含一类。用 **impurity $i(N)$** 描述节点 $N$ 有多不纯：
- 节点里全是同一类时 $i(N) = 0$；
- 各类一样多时 $i(N)$ 最大。

记 $P(\omega_j)$ 为节点 $N$ 中属于 $\omega_j$ 类的样本比例。

| 名称 | 公式 | 10 : 90 节点（课件例子） | 50 : 50 节点 |
|---|---|---|---|
| **Entropy impurity（熵不纯度）** | $i_E(N) = -\sum_j P(\omega_j)\log_2 P(\omega_j)$ | $-0.1\log_2 0.1 - 0.9\log_2 0.9 = \mathbf{0.469}$ | 1 |
| **Variance impurity（方差不纯度）**，只适用两类 | $i_{Var}(N) = P(\omega_1)P(\omega_2)$ | $0.1\times 0.9 = \mathbf{0.09}$ | 0.25 |
| **Gini impurity（基尼不纯度）**，课件版 | $i_{Gini}(N) = \sum_{j\ne k}P(\omega_j)P(\omega_k) = \tfrac12\left[1 - \sum_j P^2(\omega_j)\right]$ | $\tfrac12(1 - 0.01 - 0.81) = \mathbf{0.09}$ | 0.25 |
| **Misclassification impurity（误分类不纯度）** | $i_{MC}(N) = 1 - \max_j P(\omega_j)$ | $1 - 0.9 = \mathbf{0.1}$ | 0.5 |

**要点**：
- Gini 是 variance impurity 推广到多类的形式。两类时课件版 Gini 和 variance 完全相等：$\tfrac12(1 - p^2 - q^2) = pq$。
- **课件 Gini 带 $\tfrac12$，教科书和网上一般不带**（$1 - \sum P^2$，10 : 90 时是 0.18）。
  - 两种都只差一个常数倍，选出来的特征完全一样。
  - 考试时**写清楚你用的公式**，两种都对。
  - 25-26 S1 的参考答案用的是不带 $\tfrac12$ 的版本。
- Entropy 最常用（"computational simplicity and basis in information theory"）。课件说 "usually, the results are not affected much by the different impurity measures"。
- **不同度量的数值不能互相比较**。比较候选划分时始终用同一种。
- log 以 2 为底。计算器上 $\log_2 x = \dfrac{\ln x}{\ln 2}$。

> **看图（课件 p.12–p.13）**：p.12 是 entropy 的定义和 "pure 时为 0，各类均等时最大" 的要求。p.13 用 10 : 90 的节点算出 0.469，50 : 50 算出 1。

![课件 p.12 和 p.13](figs/dt/slides_p12_p13.png)

> **看图（课件 p.14–p.16）**：p.14 是 variance 和 Gini 的定义，注意 Gini 公式里的 $\tfrac12$。p.15 用同一个 10 : 90 节点算出两者都是 0.09。p.16 是误分类不纯度 0.1，以及 "results are not affected much"。

![课件 p.14–p.16](figs/dt/slides_p14_p16.png)

> **看图 4-1**：横轴是 $\omega_1$ 的比例。四条曲线都在两端（纯节点）为 0、在 0.5 处最大。
> - 红线（误分类）是折线，对比例变化不够敏感，所以一般不用来选划分。

## 5. 怎么选划分：Impurity drop（不纯度下降）

### 5.1 二叉划分

在节点 $N$ 用某个特征和取值把数据分成左子节点 $N_L$、右子节点 $N_R$：

$$\Delta i(N) = i(N) - P_L\, i(N_L) - P_R\, i(N_R)$$

- $P_L$、$P_R$ 是落到左、右的样本比例（$P_L + P_R = 1$）。
- $i(N)$ 对所有候选划分都一样，所以 **"最大的 $\Delta i$" 等价于 "最小的加权子节点不纯度 $P_L\,i(N_L) + P_R\,i(N_R)$"**。
- 真题和课件例子都直接比较加权子节点不纯度，取最小的。
- 用 entropy 时，$\Delta i$ 就是常说的 **information gain（信息增益）**。

### 5.2 多叉划分

分成 $B$ 支，第 $k$ 支的比例是 $P_k$：

$$\Delta i(N) = i(N) - \sum_{k=1}^{B} P_k\, i(N_k),\qquad \sum_k P_k = 1$$

**缺点**：分支越多越容易显得 "纯"，这个量偏爱大的 $B$。解决办法是除以划分本身的熵，叫 **gain ratio（增益率）**：

$$\Delta i'(N) = \frac{\Delta i(N)}{-\sum_{k=1}^{B} P_k\log_2 P_k}$$

> **看图（课件 p.17 和 p.19）**：p.17 是二叉划分的 $\Delta i$ 公式，最后一行红字 "maximum drop in impurity is equivalent to minimum impurity at the descendent nodes"，这就是做题时只比较加权子节点不纯度的依据。p.19 是 gain ratio。

## 6. 课件例子：Heart disease（心脏病）数据选根节点

数据：303 个样本，$\omega_1$（有心脏病）139 个，$\omega_2$（没有）164 个，13 个特征。其中有二值的 sex、fbs、exang，有四个取值的 cp，有连续的 age 等。

**做法：每个特征都试一遍**，算加权子节点 Gini（课件版，带 $\tfrac12$），**选最小的。**

| 候选划分 | 左支（yes）$\omega_1 : \omega_2$ | $i_{left}$ | 右支（no）$\omega_1 : \omega_2$ | $i_{right}$ | 加权 Gini |
|---|---|---|---|---|---|
| sex = 0? | 25 : 72（97 个） | 0.1913 | 114 : 92（206 个） | 0.2471 | $\frac{97}{303}(0.1913) + \frac{206}{303}(0.2471) = \mathbf{0.2293}$ |
| fbs = 0? | 117 : 141（258 个） | 0.2478 | 22 : 23（45 个） | 0.2499 | **0.2481** |
| age > 31.5? | 139 : 163（302 个） | 0.2484 | 0 : 1（1 个） | 0 | **0.2476** |
| age 的最佳分割点 54.5 | | | | | **0.228**（课件 p.28） |

左支 $i_{left}$ 的算法示范：

$$i = \frac12\left[1 - \left(\frac{25}{97}\right)^2 - \left(\frac{72}{97}\right)^2\right] = \frac12\,[1 - 0.0664 - 0.5510] = 0.1913$$

> **注意课件的一个算术问题**：p.23 把 sex 的加权 Gini 算成 0.2276，按 p.22 的数重算应该是 **0.2293**。课件接着说 "**Assume** the Gini impurity of sex is the lowest"。严格按数字算，age 在 54.5 处的 0.228 比 sex 还小。这是个假设性的演示，不影响方法，考试照方法算即可。

> **看图（课件 p.22–p.23）**：用 sex = 0? 把 303 个样本分成 97 和 206 两份，分别算 Gini，再按样本比例加权。这一页的套路和真题一模一样。

## 7. 真题精讲：25-26 S1 Q3(c)（7 分）

> 300 个样本，两类 $\omega_1$、$\omega_2$，三个二值特征。
>
> | 特征 | $\omega_1$ | $\omega_2$ |
> |---|---|---|
> | $X_1 = 1$ | 20 | 80 |
> | $X_1 = 0$ | 150 | 50 |
> | $X_2 = 1$ | 20 | 30 |
> | $X_2 = 0$ | 100 | 150 |
> | $X_3 = 1$ | 100 | 50 |
> | $X_3 = 0$ | 50 | 100 |
>
> Determine the feature to be used as the root node based on Gini impurity measure.

**标准答法**（课件版 Gini，带 $\tfrac12$）：

**第 1 步：写公式。**

$$i_{Gini}(N) = \frac12\left[1 - P^2(\omega_1) - P^2(\omega_2)\right],\qquad \text{加权不纯度} = \frac{n_L}{N}\,i(N_L) + \frac{n_R}{N}\,i(N_R)$$

**第 2 步：逐个特征计算。**

| 特征 | 分支 | 样本数 | $P(\omega_1), P(\omega_2)$ | Gini | 加权 Gini |
|---|---|---|---|---|---|
| $X_1$ | $=1$ | 100 | 0.2, 0.8 | $\tfrac12(1 - 0.04 - 0.64) = 0.16$ | $\frac{100}{300}(0.16) + \frac{200}{300}(0.1875) = \mathbf{0.1783}$ |
| | $=0$ | 200 | 0.75, 0.25 | $\tfrac12(1 - 0.5625 - 0.0625) = 0.1875$ | |
| $X_2$ | $=1$ | 50 | 0.4, 0.6 | $\tfrac12(1 - 0.16 - 0.36) = 0.24$ | $\frac{50}{300}(0.24) + \frac{250}{300}(0.24) = \mathbf{0.24}$ |
| | $=0$ | 250 | 0.4, 0.6 | 0.24 | |
| $X_3$ | $=1$ | 150 | $2/3$, $1/3$ | $\tfrac12(1 - \frac49 - \frac19) = 0.2222$ | **0.2222** |
| | $=0$ | 150 | $1/3$, $2/3$ | 0.2222 | |

**第 3 步：结论。** $X_1$ 的加权 Gini 最小（0.1783），选 **$X_1$ 作为根节点**。

**补充说明**（写一句能体现理解）：
- 用教科书版 Gini（不带 $\tfrac12$），三个数变成 0.3567、0.48、0.4444，结论相同。
- 用 entropy 算：$X_1$ 0.7815，$X_2$ 0.9710，$X_3$ 0.9183，结论也是 $X_1$。
- 题目数据本身有点问题：三张表的类别总数不一致（170/130、120/180、150/150），按各表分别算即可。

> **看图 7-1**：三个特征分完后两支的类别构成。
> - $X_2$ 两支都是 2 : 3，跟没分一样，Gini 一点没降。
> - $X_3$ 变成 2 : 1 和 1 : 2。
> - $X_1$ 变成 1 : 4 和 3 : 1，最纯。

![图 7-1](figs/dt/fig2_exam_gini.png)

**易错点**：
1. 忘了按分支样本数加权，直接把两支 Gini 相加或平均。
2. 选了最大值。要选**最小**的加权不纯度，也就是最大的 drop。
3. 比例算错：分母是**该分支**的样本数，不是 300。
4. 没写公式。7 分题里公式本身就有分。

## 8. 连续特征：找分割点

步骤（课件 p.26、p.42、p.44）：
1. 把该特征的取值**从小到大排序**。
2. 相邻两个不同取值取**中点**，作为候选分割点。
3. 对每个候选点 $t$，用 "$x < t$?" 把数据分两支，算加权不纯度。
4. 取加权不纯度最小的 $t$ 作为这个特征的分割点。
5. 再和其他特征的最小值比较，选全局最小的特征（连同它的 $t$）。

**小例子**：8 个样本，$x$ 已排序。

| $x$ | 2 | 3 | 5 | 6 | 8 | 9 | 11 | 12 |
|---|---|---|---|---|---|---|---|---|
| 类 | $\omega_1$ | $\omega_1$ | $\omega_1$ | $\omega_1$ | $\omega_2$ | $\omega_1$ | $\omega_2$ | $\omega_2$ |

| 候选 $t$ | 左 $\omega_1 : \omega_2$ | 右 $\omega_1 : \omega_2$ | 加权 $\text{Gini}_{1/2}$ |
|---|---|---|---|
| 2.5 | 1 : 0 | 4 : 3 | 0.2143 |
| 4.0 | 2 : 0 | 3 : 3 | 0.1875 |
| 5.5 | 3 : 0 | 2 : 3 | 0.1500 |
| **7.0** | **4 : 0** | **1 : 3** | **0.0938** |
| 8.5 | 4 : 1 | 1 : 2 | 0.1833 |

## 9. 何时停止、剪枝、叶节点标签

### 9.1 Stopping criteria（停止分裂的准则）

**两头都不好**：
- **一直长到每个叶子都纯**：极端情况下每个叶子只有一个训练样本，树变成了查找表（lookup table），**overfitting（过拟合）**，泛化差。
- **停得太早**：训练误差不够低，性能也差（**underfitting**）。

**常用方法**：
1. **Cross-validation（交叉验证）**：用训练集长树，长到验证集误差最小为止。
2. **Impurity reduction threshold（不纯度下降阈值）**：最好的划分也只能让 $\Delta i$ 下降不到预设的小值时停止。
   - 优点：用全部数据训练。
   - 特点：叶节点可以在不同层。
3. **最少样本数**：节点样本少于某个数（例如 10 个），或少于训练集的某个百分比时停止。
4. **Trade-off criterion（折中准则）**：最小化
   $$J = \alpha\cdot\text{size} + \sum_{\text{leaf nodes}} i(N)$$
   - size 是节点数或连线数，$\alpha > 0$。
   - 在树的复杂度和训练性能之间折中。

### 9.2 Pruning（剪枝）

先把树长满，再从下往上剪：
- 考察所有**共用同一个父节点的相邻叶子对**。
- 如果把它们合并只让不纯度增加一点点（可接受），就删掉这对叶子，把父节点变成叶子。
- 父节点之后还可以继续被剪。

合并就是分裂的逆操作。

**为什么剪枝常比提前停止好**：提前停止可能看不到 "这一步划分收益小，但下一步收益大" 的情况，这叫 horizon effect（视界效应）。先长满再剪，用到了整棵树的信息。

### 9.3 Leaf label（叶节点标签）

- 叶子纯：就标那一类。
- 叶子不纯（更常见）：标**样本最多的那一类**（majority vote，多数投票）。

> - p.54：要求每个叶子至少 10 个样本，树简单得多，边界只有两刀，10 个训练错误。
>
> 训练错误多不一定差：简单的树往往泛化更好。

## 11. Random Forest（随机森林）

### 11.1 是什么

**Random forest** 是很多棵分类树组成的 **ensemble（集成）**。
- 每棵树在不同的训练数据子集上训练。
- 预测时每棵树投一票，**得票最多的类**就是最终结果。

它基于 **Bagging = Bootstrap Aggregating**，分两步：
1. **Bootstrapping（自助抽样）**：从训练集中**有放回地随机抽样**，得到多个子集。同一个样本可能被抽到多次，有的样本一次也抽不到。
2. **Aggregating（聚合）**：把多棵树的预测合起来，通常用 **majority voting（多数投票）**。也可以加权投票，比如给表现好的树更高权重。

### 11.2 两处随机（老师在 week13 总复习强调）

| 随机在哪 | 做法 |
|---|---|
| **随机样本** | 每棵树用 bootstrap 抽出的样本子集训练 |
| **随机特征** | 每棵树只用从 $d$ 个特征中随机选的 $m$ 个（$m < d$） |

**目的**：降低树与树之间的 **correlation（相关性）**，得到 **diversity（多样性）**。树之间犯的错不一样，投票时才能互相抵消。如果每棵树都一样，投票就没有意义了。

### 11.3 步骤（课件 p.63、p.65）

设训练集有 $N$ 个样本、$d$ 个特征。

**建森林**：
1. 用 bootstrapping 生成 $n$ 个数据子集 subset 1, …, subset $n$。
2. 对每个子集，从 $d$ 个特征里随机选 $m$ 个（$m < d$），用这 $m$ 个特征建一棵分类树。
3. 重复第 2 步，直到 $n$ 个子集都用完。

**分类一个测试样本**：

1. 把样本送进 $n$ 棵树，各得一个预测类别。
2. 统计每个类别的票数。
3. 输出票数最多的类别。

> **看图（课件 p.61 和 p.63）**：p.61 上半是 **with replacement（有放回）**抽样，同一个号码会在一个样本里出现两次；下半是无放回抽样。p.63 是建森林的三步。

![课件 p.61 和 p.63](figs/dt/slides_p61_p63.png)

### 11.4 随机森林的特点（课件 p.66）

1. **Diversity（多样性）**：每棵树用的样本和特征都不同，每棵树都不一样。
2. **Immune to the curse of dimensionality（缓解维数灾难）**：每棵树只用一部分特征，特征空间变小了。
3. **Parallelization（可并行）**：每棵树独立训练。
4. **Train-test split**：每棵树总有没被抽到的数据（out-of-bag），可以用来评估，不一定要另外划测试集。
5. **Stability（稳定）**：结果来自多数投票或平均。

### 11.5 随机森林 vs 单棵分类树（课件 p.67，可直接当论述题答案）

| 方面 | Random forest | Classification tree |
|---|---|---|
| 本质 | 多棵树的集成 | 单棵树 |
| Variance（方差） | 低，减少过拟合 | 高，容易过拟合 |
| Accuracy（精度） | 通常更高 | 容易过拟合，结果波动 |
| Robustness（鲁棒性） | 对离群点和噪声更鲁棒 | 对离群点和噪声敏感 |
| 训练时间 | 慢，要建很多树 | 快 |
| Interpretability（可解释性） | 差 | 好 |
| 适用 | 复杂、高维任务 | 简单任务、需要解释的场合 |

## 12. 论述题范文（英文，可直接写）

### E1. Why use classification trees? / Advantages and disadvantages（6 分）
（为什么要用分类树？它的优点和缺点。）

> Classification trees are non-metric classifiers. Many applications involve **nominal data** such as colour or transportation mode, whose values are only labels without quantitative meaning, so the Euclidean distance does not reflect similarity and distance-based classifiers may not work well. A tree classifies a sample through a sequence of simple questions about individual features, so it needs no distance measure.
>
> **Advantages:** (1) high **interpretability**: the tree is equivalent to a set of if–then rules that can be easily understood; (2) prior knowledge from human experts can be naturally incorporated; (3) it handles mixed numerical and categorical features; (4) classification is fast.
>
> **Disadvantages:** (1) a fully grown tree easily **overfits** the training data, so stopping criteria or pruning are needed; (2) it has high variance and is sensitive to noise and outliers: a small change in the data can change the tree a lot; (3) the decision boundaries are axis-parallel, so oblique boundaries need many splits.

> 【中文】分类树是非度量（non-metric）分类器。很多应用涉及**名义数据**，如颜色、交通方式，它们的取值只是标签，没有数量意义，欧氏距离反映不了相似性，基于距离的分类器可能效果不好。分类树通过一连串针对单个特征的简单问题来分类，不需要任何距离度量。
>
> **优点**：(1) **可解释性**强：一棵树等价于一组容易理解的 if–then 规则；(2) 可以自然地融入人类专家的先验知识；(3) 能同时处理数值和类别特征；(4) 分类速度快。
>
> **缺点**：(1) 完全长成的树容易**过拟合**训练数据，需要停止准则或剪枝；(2) 方差大，对噪声和离群点敏感：数据稍有变化，树可能变化很大；(3) 决策边界平行于坐标轴，斜的边界需要很多次划分。

### E2. Describe how to construct a classification tree（8 分）
（描述如何构建一棵分类树。）

> To build a tree from labelled training data we must answer five questions: (1) how many splits at each node (binary or multi-way); (2) which property, and which value, should be tested at a node; (3) when a node should be declared a leaf; (4) how to prune a tree that is too large; and (5) how to assign a label to an impure leaf.
>
> Following the principle of **simplicity**, at each node we choose the test that makes the descendent nodes as pure as possible. The impurity of a node is measured by, e.g., entropy $i(N) = -\sum_j P(\omega_j)\log_2 P(\omega_j)$ or Gini impurity $i(N) = \tfrac12\left[1 - \sum_j P^2(\omega_j)\right]$. Every candidate feature, and every candidate value (for a continuous feature, the midpoints of adjacent sorted values), is tried. The test that maximizes the impurity drop $\Delta i = i(N) - P_L\,i(N_L) - P_R\,i(N_R)$, i.e., minimizes the weighted impurity of the children, is selected. The procedure is applied recursively to each child.
>
> Splitting stops by cross-validation, by a threshold on the impurity reduction, or by a minimum number of samples in a node. The grown tree can then be pruned by merging neighbouring leaves whose elimination causes only a small increase in impurity. Each leaf is labelled by the majority class of its samples.

> 【中文】用带标签的训练数据建树，要回答五个问题：(1) 每个节点分几支（二叉还是多叉）；(2) 节点上测试哪个属性、哪个取值；(3) 什么时候把节点定为叶子；(4) 树太大时怎么剪枝；(5) 不纯的叶子怎么标类别。
>
> 遵循**简单性**原则，在每个节点选择使子节点尽可能纯的测试。节点的不纯度用熵 i(N) = −Σⱼ P(ωⱼ) log₂ P(ωⱼ) 或 Gini 不纯度 i(N) = ½[1 − Σⱼ P²(ωⱼ)] 等衡量。尝试每个候选特征和每个候选取值（连续特征取排序后相邻取值的中点），选使不纯度下降 Δi = i(N) − P_L·i(N_L) − P_R·i(N_R) 最大、即子节点加权不纯度最小的测试。对每个子节点递归地重复这一过程。
>
> 停止划分可以用交叉验证、不纯度下降的阈值或节点最少样本数来决定。长成的树还可以剪枝：合并那些去掉后不纯度只略微增加的相邻叶子。每个叶子按其样本的多数类标注。

### E3. Compare entropy and Gini impurity（4 分）
（比较熵和 Gini 不纯度。）

> Both are zero when all samples at a node belong to one class and maximal when classes are equally represented. Entropy, $-\sum P\log_2 P$, comes from information theory, and its impurity drop is the information gain. Gini, $\tfrac12\left[1 - \sum P^2\right]$, is a generalization of the variance impurity $P(\omega_1)P(\omega_2)$ to more than two classes and needs no logarithm. In practice they usually select the same splits. Their values are on different scales, so splits must be compared using the same measure. The misclassification impurity $1 - \max P$ is less sensitive to changes in class proportions and is seldom used to grow trees.

> 【中文】两者在节点所有样本都属于同一类时为 0，在各类数量相等时最大。熵 −ΣP log₂P 来自信息论，它的不纯度下降就是信息增益。Gini ½[1 − ΣP²] 是方差不纯度 P(ω₁)P(ω₂) 推广到多类的形式，不需要算对数。实际中两者通常选出相同的划分。它们的数值尺度不同，所以比较候选划分时必须用同一种度量。误分类不纯度 1 − max P 对类别比例的变化不够敏感，很少用来建树。

### E4. Overfitting in trees: when to stop splitting and pruning（6 分）
（树的过拟合：何时停止划分，以及剪枝。）

> If a tree is grown until every leaf is pure, in the extreme each leaf contains a single training sample and the tree becomes a lookup table, which overfits and generalizes poorly. If splitting stops too early, the training error remains high (underfitting).
>
> **Stopping criteria:** (1) **cross-validation**: keep splitting while the validation error decreases; (2) stop when the best split reduces the impurity by less than a preset **threshold**; (3) stop when a node has fewer than a minimum number of samples, or a fixed percentage of the data; (4) minimize a **trade-off criterion** $\alpha\cdot\text{size} + \sum_{\text{leaves}} i(N)$, which balances tree complexity against performance.
>
> **Pruning:** grow the full tree first, then consider every pair of neighbouring leaves with a common parent, and eliminate the pair if merging causes only a small increase in impurity; the parent becomes a leaf. Pruning avoids the horizon effect of stopping too early, because it uses information from the whole tree.

> 【中文】如果一直划分到每个叶子都纯，极端情况下每个叶子只含一个训练样本，树就成了一张查找表，会过拟合、泛化差。如果停得太早，训练误差仍然很高（欠拟合）。
>
> **停止准则**：(1) **交叉验证**：只要验证误差还在下降就继续划分；(2) 最佳划分带来的不纯度下降小于预设**阈值**时停止；(3) 节点样本数少于最小值或数据的某个固定比例时停止；(4) 最小化**权衡准则** α·size + Σ_叶子 i(N)，平衡树的复杂度和性能。
>
> **剪枝**：先把整棵树长满，再考察每一对有共同父节点的相邻叶子，如果合并它们只使不纯度略微增加，就消去这对叶子，父节点变成叶子。剪枝利用了整棵树的信息，因此避免了过早停止带来的"视界效应"（horizon effect）。

### E5. Random forest: bootstrapping and aggregating（8 分，总复习 p.17）
（随机森林：自助采样与聚合。）

> A random forest is an **ensemble** of classification trees based on **Bagging (Bootstrap Aggregating)**.
>
> **Bootstrapping:** from a training set of $N$ samples with $d$ features, $n$ data subsets are generated by random sampling **with replacement**, so a sample may appear several times in a subset and some samples do not appear at all. For each subset, $m$ features ($m < d$) are randomly selected, and a classification tree is built using these $m$ features.
>
> **Aggregating:** a test sample is passed through all $n$ trees; each tree predicts a class, the votes are counted, and the class with the most votes (**majority voting**) is the output.
>
> The two sources of randomness, random samples and random features, reduce the correlation between the trees and create **diversity**. The individual trees make different errors, which cancel out when the votes are combined. Therefore the forest has lower variance, less overfitting, higher accuracy and more robustness to noise and outliers than a single tree. Since each tree uses only a subset of features, it alleviates the curse of dimensionality. The trees can be trained in parallel, and the samples left out of each bootstrap subset can be used for evaluation.

> 【中文】随机森林是基于 **Bagging（Bootstrap Aggregating，自助聚合）** 的分类树**集成**。
>
> **自助采样（Bootstrapping）**：从含 N 个样本、d 个特征的训练集中，通过**有放回**随机抽样生成 n 个数据子集，所以一个样本可能在某个子集中出现多次，有些样本根本不出现。对每个子集，随机选 m 个特征（m < d），用这 m 个特征建一棵分类树。
>
> **聚合（Aggregating）**：测试样本经过全部 n 棵树，每棵树预测一个类别，统计票数，得票最多的类（**多数投票**）就是输出。
>
> 两处随机性——随机样本和随机特征——降低了树之间的相关性，产生**多样性**。各棵树犯的错误不同，投票合并时相互抵消。所以森林比单棵树方差更小、过拟合更少、准确率更高，对噪声和离群点更稳健。每棵树只用一部分特征，因此也缓解了维数灾难。各棵树可以并行训练，每个 bootstrap 子集没抽到的样本可以用来评估。

### E6. Compare random forest with a single classification tree（6 分）
（比较随机森林和单棵分类树。）

> A single tree is fast to train and highly interpretable, but it has **high variance**: it is prone to overfitting and sensitive to noise and outliers. A random forest combines many trees trained on bootstrap samples with random feature subsets, so it has **lower variance**, generally higher accuracy and greater robustness, and suits complex, high-dimensional tasks. Its costs are a longer training time (many trees) and loss of interpretability, because the decision is a vote of many trees rather than a single set of rules.

> 【中文】单棵树训练快、可解释性强，但**方差大**：容易过拟合，对噪声和离群点敏感。随机森林组合了许多在 bootstrap 样本和随机特征子集上训练的树，所以**方差更小**，通常准确率更高、更稳健，适合复杂的高维任务。代价是训练时间更长（要训练很多棵树），并且失去可解释性，因为决策是许多棵树的投票，而不是一组规则。

### E7. How to handle a continuous feature in a tree（4 分）
（树中如何处理连续特征。）

> Sort the values of the feature in ascending order and take the midpoint of every two adjacent distinct values as a candidate splitting point. For each candidate $t$, split the data by "$x < t$?" and compute the weighted impurity of the two children. The candidate with the lowest impurity is the splitting point of this feature, and its impurity is compared with those of the other features to choose the test at the node. (ID3 instead bins the continuous values into intervals and treats them as nominal values.)

> 【中文】把该特征的取值从小到大排序，相邻两个不同取值的中点作为候选分割点。对每个候选点 t，按"x < t？"把数据分成两支，计算两个子节点的加权不纯度。不纯度最低的候选点就是这个特征的分割点，再把它的不纯度和其他特征比较，选出节点上的测试。（ID3 则把连续值分箱成若干区间，当作名义值处理。）
