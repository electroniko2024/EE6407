### 1(b) 黑盒问题分类与电梯调度（7 分）

**考点**："输入 → 模型 → 输出"黑盒，哪个未知决定问题类型。

**Answer**

A system is a **black box with three components: input, model, output**. **If one is unknown** we get three problem types:

| Type | Known | Unknown | Example |
|---|---|---|---|
| **Optimisation** | model + desired output | **input** | TSP, timetabling, 8 queens |
| **Modelling** | input + output (data) | **model** | machine learning, system identification |
| **Simulation** | input + model | **output** | weather forecasting, what-if analysis |

**Elevator control:**

- **Primarily an optimisation problem:** the building/elevator behaviour (model) is known or simulable, the desired output is "fair and efficient" service, **the unknown is the input — the dispatch policy**.
- **Multi-objective:** **"efficient"** (low mean waiting/travel time, energy) and **"fair"** (low maximum waiting time, no floor starved) **conflict** → weighted sum or Pareto solutions.
- **Constrained:** capacity limits, number of cars, etc. → **constrained optimisation**.
- **Evaluating a policy needs simulation** (policy + passenger arrivals → waiting times), which serves as fitness; if passenger flow is unknown it must first be **modelled** from data. **Huge search space and no closed-form objective → GA is suitable.**

**【中文】** 黑盒有输入、模型、输出三部分，未知哪个就是哪类问题：未知输入 = 优化，未知模型 = 建模，未知输出 = 仿真。电梯问题：**主体是优化问题**（未知的是调度策略这个输入）；**多目标**（efficient 与 fair 冲突）；**带约束**；评价策略需要**仿真**，客流模式未知则需先**建模**；搜索空间大、目标无解析式，适合 GA。

**易错点**：只背三类定义而不回答电梯属于哪类、为什么；漏掉 fair 与 efficient 是两个目标。

## Question 2

### 2(a) Fisher LDA 的优化表述与原理（12 分）

**Answer**

**LDA seeks a direction $\mathbf w$ that projects $d$-dimensional samples to one dimension $y=\mathbf w^T\mathbf x$ so that the two classes are as well separated as possible.** Projected means and scatters:

$$\tilde m_i=\mathbf w^T\mathbf m_i,\qquad\tilde s_i^2=\sum_{\mathbf x\in D_i}(\mathbf w^T\mathbf x-\tilde m_i)^2=\mathbf w^T\mathbf S_i\mathbf w$$

**Optimisation problem (Fisher criterion):**

$$\max_{\mathbf w}\ J(\mathbf w)=\frac{(\tilde m_1-\tilde m_2)^2}{\tilde s_1^2+\tilde s_2^2}=\frac{\mathbf w^T\mathbf S_B\mathbf w}{\mathbf w^T\mathbf S_W\mathbf w}$$

- **$\mathbf S_B=(\mathbf m_1-\mathbf m_2)(\mathbf m_1-\mathbf m_2)^T$: between-class scatter**
- **$\mathbf S_W=\mathbf S_1+\mathbf S_2$, $\mathbf S_i=\sum_{\mathbf x\in D_i}(\mathbf x-\mathbf m_i)(\mathbf x-\mathbf m_i)^T$: within-class scatter**

**Solution:** $\partial J/\partial\mathbf w=0$ gives $\mathbf S_B\mathbf w=\lambda\mathbf S_W\mathbf w$; since $\mathbf S_B\mathbf w$ is along $(\mathbf m_1-\mathbf m_2)$,

$$\mathbf w^*=\mathbf S_W^{-1}(\mathbf m_1-\mathbf m_2),\qquad g(\mathbf x)=\mathbf w^T\mathbf x+w_0,\ \ w_0=-\tfrac12\mathbf w^T(\mathbf m_1+\mathbf m_2)$$

**Rationale:** **large numerator → projected class centres far apart; small denominator → each class compact.** **Maximising the mean difference alone is not enough** (a large within-class variance still overlaps); **the ratio balances "far apart" and "compact"**, and $\mathbf S_W^{-1}$ corrects the mean-difference direction by the within-class variance. **$J$ is scale-invariant in $\mathbf w$**, so only direction matters.

**【中文】** LDA 寻找投影方向 $\mathbf w$，把样本投影到一维 $y=\mathbf w^T\mathbf x$，使两类尽可能分开。**优化问题**：最大化 Fisher 比 $J(\mathbf w)$＝（投影后类间距离）²/（投影后类内散度之和），其中 $\mathbf S_B$ 为类间散度矩阵，$\mathbf S_W$ 为类内散度矩阵。求解得广义特征值问题，最优解 $\mathbf w^*=\mathbf S_W^{-1}(\mathbf m_1-\mathbf m_2)$，阈值取投影均值中点。原理：分子大 → 类间可分；分母小 → 类内紧凑；只让均值差最大不够，比值同时兼顾两者，得到重叠最小的方向；$J$ 对 $\mathbf w$ 的尺度不敏感。

**易错点**：只写 $\mathbf w=\mathbf S_W^{-1}(\mathbf m_1-\mathbf m_2)$ 而不写优化目标；$\mathbf S_B$、$\mathbf S_W$ 定义和"分子/分母各代表什么"都要写。

### 4(c) Dunn Index（7 分）

**Answer**

For clusters $\{D_1,\dots,D_k\}$: inter-cluster separation $d_{pq}=\min_{\mathbf x_i\in D_p,\mathbf x_j\in D_q}d(i,j)$; **cluster diameter** $\delta_p=\max_{\mathbf x_i,\mathbf x_j\in D_p}d(i,j)$ (compactness);

$$DI=\frac{\min_{p\ne q}d_{pq}}{\max_p\delta_p}$$

**Rationale:** a good clustering is **compact and well separated**. The numerator is the **smallest** inter-cluster distance and the denominator the **largest** cluster diameter, so **DI measures the worst case**. **Larger DI → better clustering.** It is an **internal index (no labels needed)**, usable to compare algorithms or **choose $k$ (largest DI)**. **Drawbacks:** relies on extreme values, **sensitive to noise and outliers**; needs all pairwise distances, **expensive for large data**.

**【中文】** $DI$ ＝（所有簇对中最近的簇间距离）/（所有簇中最大的簇内直径）。好的聚类应簇内紧凑、簇间分离，$DI$ 衡量**最坏情况**：最靠近的两簇与最松散的簇之比；**越大越好**。它是**内部指标，不需真实标签**，可比较算法或选 $k$。缺点：只依赖极值，对噪声和离群点敏感；需计算所有样本对距离，数据量大时开销高。

**易错点**：分子分母写反；min/max 混淆（分子取 min、分母取 max）；只写公式不解释"越大越好"。
